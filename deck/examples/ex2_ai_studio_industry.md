# 강의 PPT 제작 지침서 ② — Google AI Studio 산업별 데이터 시각화 실습

> 이 문서는 강의 슬라이드(PPT)를 만드는 사람 또는 AI에게 주는 작업 지침이다.
> 이 문서 하나만 보고 덱 한 벌을 만들 수 있게 쓴다.
> `[확정 필요]`는 저자가 값을 채워야 하는 자리다.

---

## 0. 덱 한눈에 보기

| 항목 | 내용 |
|---|---|
| 덱 제목 | Google AI Studio로 만드는 산업별 데이터 시각화 |
| 분량 | **40장 내외 (38~42장)** |
| 대상 | 처음 배우는 사람. 코딩 경험 없음을 기준으로 한다 |
| 방식 | 프롬프트를 여러 번 이어 입력해 대시보드를 완성하는 따라하기 실습 |
| 산업 | 헬스케어 · 의료데이터 · 핀테크 `[확정 필요: 추가 산업]` |
| 주 도구 | Qwen — 쉬운 작업(데이터 알아보기, 차트 1개) |
| 보조 도구 | Google AI Studio — 어려운 작업(여러 차트가 함께 움직이는 대시보드) |
| 과목·주차 | `[확정 필요]` |
| 덱 제작 도구 | **Genspark** (AI 슬라이드 기능) |
| 언어판 | **한국어판 1벌 + 중국어판 1벌**, 각각 별도 폴더에 PPT로 저장 |

핵심 메시지: **"쉬운 일은 Qwen으로, 어려운 일은 Google AI Studio로. 산업이 달라도 묻는 순서는 같다."**

학습 목표 (슬라이드에는 이 3개만 싣는다)
1. Qwen으로 할 일과 Google AI Studio로 할 일을 구분한다.
2. 프롬프트를 이어 입력해 대시보드를 만든다.
3. 산업마다 보는 사람이 원하는 숫자가 다르다는 것을 설명한다.

## 1. 초보자를 위한 작성 원칙 (가장 중요)

1. **한 장에 한 동작.** 클릭과 입력을 한 장에 섞지 않는다.
2. **새 용어는 나온 그 장에서 바로 풀이한다.**
   예: 대시보드(여러 차트를 한 화면에 모은 판), 필터(보고 싶은 것만 골라 보는 단추)
3. **영어 약어는 처음 한 번 풀어 쓴다.** 예: CSV(쉼표로 값을 나눈 표 파일)
4. **프롬프트는 복사해서 그대로 쓸 수 있는 원문으로 싣는다.** 고쳐 써야 하는 부분만 색으로 표시한다.
5. **프롬프트 장에는 결과 화면을 함께 또는 바로 다음 장에 싣는다.**
6. **따라하기 장에는 클릭 순서를 번호 원형(①②③)으로 표시한다.** 한 장에 3단계까지.
7. **"내 화면이 달라요" 안내를 넣는다.** AI 결과는 매번 조금씩 다르다. 달라도 정상이라고 적는다.
8. **막혔을 때 쓸 문장을 준다.** 예: "화면이 안 나와. 원인을 쉬운 말로 설명하고 고쳐줘."
9. **본문은 5줄 이내, 한 줄 25자 이내.**
10. **코드는 본문에 싣지 않는다.** 코드는 AI가 만들고, 학생은 결과 화면만 본다.
11. **세 산업은 똑같은 순서와 똑같은 장 배치로 만든다.** 두 번째 산업부터는 학생이 순서를 예상할 수 있어야 한다.
12. **산업마다 "여기까지 됐나요?" 확인 장을 둔다.**

## 2. 도구 나누기 규칙

| 이런 작업은 | 이 도구로 | 이유(쉬운 말) |
|---|---|---|
| 표 설명 듣기, 질문 정하기 | Qwen | 묻고 답하기만 하면 된다 |
| 차트 1개 만들기 | Qwen | 한 화면에 그림 하나면 충분하다 |
| 차트 3개 이상이 함께 움직이는 대시보드 | Google AI Studio | 여러 부품을 한꺼번에 맞춰야 한다 |
| 필터를 누르면 전체가 바뀌는 화면 | Google AI Studio | 차트끼리 연결해야 한다 |
| 지도, 움직이는 그림 | Google AI Studio | 만들 것이 많고 복잡하다 |
| Qwen에서 같은 오류가 두 번 날 때 | Google AI Studio | 도구를 바꾸는 편이 빠르다 |

도구 화면 설명 장 규칙
- 메뉴 이름과 단추 위치는 자주 바뀐다. **덱을 만들기 직전에 실제 화면을 열어 캡처한다.**
- 요금·한도·모델 이름은 본문에 고정해 쓰지 않고 "수업일 기준"이라고 적는다.

## 3. 프롬프트 사슬 (세 산업 공통 5단계)

| 단계 | 도구 | 학생이 하는 일 | 쉬운 말 설명 |
|---|---|---|---|
| Q1 | Qwen | 파일을 올리고 설명을 부탁한다 | "이 표에 뭐가 들어 있어?" |
| Q2 | Qwen | 차트 1개를 만들어 본다 | "먼저 하나만 그려줘" |
| S1 | AI Studio | 대시보드 뼈대를 만든다 | "차트 세 개를 한 화면에 모아줘" |
| S2 | AI Studio | 필터를 달아 차트를 연결한다 | "고르면 다 같이 바뀌게 해줘" |
| S3 | AI Studio | 제목·색·주석을 다듬는다 | "더 보기 좋게 고쳐줘" |

프롬프트 틀 (모든 프롬프트 장에 같은 순서로 쓴다)

```
[역할] 너는 ○○ 산업의 데이터 분석가야.
[데이터] 올린 파일은 ○○이고, 열은 A, B, C야.
[요청] ○○을 보여주는 대시보드를 만들어줘. 차트는 ○○, ○○, ○○ 세 개야.
[조건] 제목은 한국어, 단위 표시, 색은 3가지 이내, "수업용 가상 데이터" 표기.
```

프롬프트 번호 규칙: `헬스-Q1`, `의료-S2`, `핀-S3` (산업-단계)

## 4. 산업별 실습 설계

| 산업 | 누가 보는가 | 질문 | 데이터 열(예시) | 대시보드 차트 3개 | 필터 |
|---|---|---|---|---|---|
| 헬스케어 | 건강을 관리하는 개인 | 내 생활 습관은 어떻게 변했나 | 날짜, 걸음 수, 수면 시간, 평균 심박 | 걸음 수 추세선 / 수면 달력 히트맵 / 목표 달성 게이지 | 기간(주·월) |
| 의료데이터 | 병원 운영 담당자 | 환자가 어디에, 언제 몰리나 | 날짜, 요일, 시간대, 진료과, 환자 수, 대기 시간 | 진료과별 막대 / 요일×시간 히트맵 / 대기 시간 추세선 | 진료과 |
| 핀테크 | 서비스 기획자 | 돈은 언제, 어디에 쓰이나 | 날짜, 시간, 업종, 결제 수단, 금액, 이상 거래 여부 | 일별 거래액 선 / 업종별 막대 / 금액 산점도(이상 거래 강조) | 결제 수단 |

개인정보 규칙 (필수 장으로 넣는다)
- **실제 사람의 의료 기록·거래 내역은 절대 쓰지 않는다.** 수업용 가상 데이터 또는 공공 통계만 쓴다.
- 이름·주민번호·계좌번호·전화번호 열은 데이터에 넣지 않는다.
- 학생에게 "내 병원 기록, 내 카드 내역을 올리지 마세요"라고 슬라이드에 적는다.
- 대시보드 화면에 "수업용 가상 데이터"라고 표기한다.

데이터 규칙
- 산업마다 CSV 1개, 열 6~8개, 1,000행 안팎. `[확정 필요: 가상 데이터를 만들지, 공공 통계를 쓸지]`
- 열 이름은 한국어로 쓴다.

## 6. 슬라이드 유형별 필수 요소

| 유형 | 필수 요소 |
|---|---|
| 산업 소개 | 보는 사람, 알고 싶은 것 한 문장, 일상 예시 1개 |
| 데이터 | 열 풀이(열 이름·뜻·단위), "수업용 가상 데이터" 표기 |
| 따라하기 | 화면 캡처, 번호 원형 3개 이내 |
| 프롬프트 | 번호, 도구 칩, 원문 상자, 고쳐 쓸 부분 색 표시 |
| 전환 | Qwen 결과 → AI Studio로 가는 화살표, 이유 한 줄 |
| 결과 | 화면 캡처, "여기를 보세요" 표시 1~2곳 |
| 확인 | 완성 화면, 확인 항목 3개, 막혔을 때 쓸 문장 |

발표자 노트: 모든 장에 말할 내용 2~4문장과 예상 질문 1개를 쓴다.

디자인: `[확정 필요: 기존 강의 덱 스타일 사용 여부]`. 도구 칩 색은 Qwen과 AI Studio를 서로 다른 색으로 고정하고, 산업마다 구분 색을 하나씩 정한다.

## 7. 좋은 대시보드 기준

- 맨 위 제목이 질문에 답한다 (예: "월요일 오전, 내과가 가장 붐빈다").
- 차트는 3개, 가장 중요한 차트가 가장 크다.
- 모든 차트에 축 이름과 단위가 있다.
- 색은 3가지 이내, 강조할 곳만 진하게.
- 필터는 1개, 눌렀을 때 세 차트가 함께 바뀐다.
- "수업용 가상 데이터" 표기와 기간이 있다.
- 해석은 세 문장: 무엇이 보이는가 → 왜 그럴까(추측임을 밝힘) → 무엇을 하면 좋을까.

## 언어판과 제작 도구 (Genspark)

### 가. 만드는 것
같은 내용의 덱을 **한국어판과 중국어판 두 벌**로 만든다. 두 벌은 서로 다른 폴더에 따로 저장한다. 한 파일에 두 언어를 섞지 않는다.

### 나. 폴더 구조

```
지침서2_AI스튜디오_산업별/
├─ ko/                                  ← 한국어판
│  ├─ AI스튜디오_산업별_시각화_ko.pptx
│  ├─ 프롬프트모음_ko.txt
│  ├─ data/      (산업별 CSV 3개, 열 이름 한국어)
│  └─ captures/  (한국어 프롬프트로 얻은 결과 화면)
└─ zh/                                  ← 중국어판
   ├─ AI_Studio_行业数据可视化_zh.pptx
   ├─ 提示词合集_zh.txt
   ├─ data/      (산업별 CSV 3개, 열 이름 중국어)
   └─ captures/  (중국어 프롬프트로 얻은 결과 화면)
```

### 다. Genspark 제작 순서
1. **한국어판을 먼저 만든다.** Genspark에 이 지침서 전체를 붙이고 아래 "한국어판 요청문"을 입력한다.
2. 40장 구성표(5절)와 장 번호·제목이 맞는지, 세 산업의 장 배치가 같은지 확인하고, 틀린 장은 장 번호를 지정해 고친다.
3. PPT 파일(.pptx)로 내려받아 `ko/` 폴더에 넣는다.
4. **중국어판은 새 작업으로 따로 만든다.** 확정된 한국어판과 이 지침서를 함께 주고 "중국어판 요청문"을 입력한다.
5. PPT 파일로 내려받아 `zh/` 폴더에 넣는다.
6. 두 파일을 PowerPoint에서 열어 글자 깨짐, 줄 넘침, 장 수를 확인한다.

※ Genspark의 메뉴 이름과 내려받기 방식은 바뀔 수 있다. 제작 당일 화면을 기준으로 한다.

한국어판 요청문

```
첨부한 지침서를 그대로 따라 강의 슬라이드를 만들어줘.
- 언어: 한국어
- 장 수: 40장 (지침서 5절의 번호·유형·제목을 그대로 사용)
- 대상: 처음 배우는 사람. 지침서 1절의 초보자 원칙을 모두 지켜.
- 헬스케어·의료데이터·핀테크 세 묶음은 똑같은 배치로 만들어.
- 프롬프트 장: 원문을 고정폭 글꼴 상자에 넣어.
- 화면 캡처 자리는 "캡처 넣을 곳" 상자로 비워 둬.
- 모든 장에 발표자 노트를 써.
- 편집 가능한 PPT 파일(.pptx)로 내보낼 수 있게 만들어.
```

중국어판 요청문

```
첨부한 한국어 슬라이드와 지침서를 바탕으로 중국어판을 새로 만들어줘.
- 언어: 중국어 간체. 한국어 글자를 한 글자도 남기지 마.
- 장 수, 장 번호, 장 순서, 배치는 한국어판과 똑같이 해.
- 직역하지 말고 중국어권 초보자가 읽기 쉬운 문장으로 써.
- 프롬프트 원문도 중국어로 바꿔. [역할][데이터][요청][조건] 틀은 유지해.
- 데이터 열 이름과 대시보드 제목·단위·필터 이름도 중국어로 바꿔.
- 발표자 노트도 중국어로 써.
- 편집 가능한 PPT 파일(.pptx)로 내보낼 수 있게 만들어.
```

### 라. 중국어판 규칙
- 글자: 간체를 기본으로 한다. `[확정 필요: 간체/번체]`
- **프롬프트는 번역만 하지 말고 중국어로 Qwen과 Google AI Studio에 실제로 입력해 결과를 다시 확인한다.** 결과 화면 캡처도 중국어 결과로 새로 찍는다.
- 산업별 CSV의 열 이름을 중국어로 바꾼 파일을 따로 만든다 (예: `日期`, `步数`, `睡眠时长`).
- 프롬프트 번호도 중국어로 바꾼다: `健康-Q1`, `医疗-S2`, `金融-S3`.
- 용어는 아래 표로 통일한다. 표에 없는 용어는 추가한 뒤 쓴다.

| 한국어 | 중국어 |
|---|---|
| 데이터 시각화 | 数据可视化 |
| 헬스케어 | 健康管理 |
| 의료데이터 | 医疗数据 |
| 핀테크 | 金融科技 |
| 프롬프트 | 提示词 |
| 대시보드 | 仪表板 |
| 필터 | 筛选器 |
| 히트맵 | 热力图 |
| 산점도 | 散点图 |
| 이상 거래 | 异常交易 |
| 수업용 가상 데이터 | 教学用虚拟数据 |

- 글꼴: 한국어판과 중국어판 모두 해당 언어를 지원하는 글꼴을 쓴다. 중국어판에 한국어 글꼴을 쓰면 글자가 깨진다.
- 중국어는 같은 뜻이라도 글자 수가 줄어든다. 빈자리가 크면 글자 크기를 키우고, 내용을 더 넣지 않는다.
- 개인정보 주의 장(9번)은 중국어판에서도 빠뜨리지 않는다.
- **도구 접속 확인이 먼저다.** Google AI Studio는 지역에 따라 접속이 안 될 수 있다. 중국어판 수강생이 있는 곳에서 접속되는지 확인하고, 안 되면 S1~S3 단계를 맡을 대체 도구를 정한 뒤 6~7번 장을 그 도구로 바꾼다. `[확정 필요: 중국어판 수강 대상과 수업 장소]`

## 8. 완성 전 점검표

- [ ] 한국어판은 `ko/`, 중국어판은 `zh/` 폴더에 PPT 파일로 따로 있다.
- [ ] 두 판의 장 수와 장 번호가 같다.
- [ ] 중국어판에 한국어 글자가 남아 있지 않다 (본문·차트·캡처·노트).
- [ ] 중국어 프롬프트를 실제로 입력해 결과를 확인했다.
- [ ] 장 수가 38~42장이다.
- [ ] 모든 프롬프트를 실제로 입력해 결과를 확인했다 (수업 1주일 이내).
- [ ] 화면 캡처가 지금 도구 화면과 같다.
- [ ] 세 산업의 장 배치가 서로 같다.
- [ ] 새 용어마다 괄호 풀이가 있다.
- [ ] 개인정보 주의 장이 있다.
- [ ] 산업마다 "여기까지 됐나요?" 장이 있다.
- [ ] 본문이 5줄을 넘는 장이 없다.
- [ ] 모든 장에 발표자 노트가 있다.
- [ ] 산업별 CSV와 프롬프트 모음(txt)을 덱과 함께 나눠 준다.
