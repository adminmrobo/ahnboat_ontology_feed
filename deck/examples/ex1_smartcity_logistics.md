> 이 문서는 강의 슬라이드(PPT)를 만드는 사람 또는 AI에게 주는 작업 지침이다.
> 이 문서 하나만 보고 덱 한 벌을 만들 수 있게 쓴다.
> `[확정 필요]`는 저자가 값을 채워야 하는 자리다.

2. 질문에 맞는 차트를 고른다.
3. Qwen에 프롬프트를 이어 입력해 차트를 만들고 세 문장으로 해석한다.

## 1. 초보자를 위한 작성 원칙 (가장 중요)

1. **한 장에 한 동작.** "파일 올리기"와 "프롬프트 입력"을 한 장에 넣지 않는다.
2. **새 용어는 나온 그 장에서 바로 풀이한다.** 괄호 한 줄로 쓴다.
   예: 히트맵(숫자가 클수록 진한 색으로 칠한 표)
3. **영어 약어는 처음 한 번 풀어 쓴다.** 예: CSV(쉼표로 값을 나눈 표 파일)
4. **프롬프트는 복사해서 그대로 쓸 수 있는 원문으로 싣는다.** 고쳐 써야 하는 부분만 색으로 표시한다.
5. **프롬프트 장 다음에는 반드시 결과 화면 장이 온다.**
6. **따라하기 장에는 클릭 순서를 번호 원형(①②③)으로 표시한다.** 한 장에 3단계까지.
7. **"내 화면이 달라요" 안내를 넣는다.** AI 결과는 매번 조금씩 다르다. 달라도 정상이라고 실습 첫 장에 적는다.
8. **막혔을 때 쓸 문장을 준다.** 예: "오류가 났어. 원인을 쉬운 말로 설명하고 고쳐줘."
9. **본문은 5줄 이내, 한 줄 25자 이내.** 넘으면 장을 나눈다.
10. **수식·코드는 본문에 싣지 않는다.** 코드는 AI가 만들고, 학생은 결과만 본다.
11. **실습마다 "여기까지 됐나요?" 확인 장을 둔다.** 완성 화면과 확인 항목 3개.

## 2. 프롬프트 사슬 (실습 공통 5단계)

| 단계 | 이름 | 학생이 하는 일 | 쉬운 말 설명 |
|---|---|---|---|
| P1 | 데이터 알아보기 | 파일을 올리고 설명을 부탁한다 | "이 표에 뭐가 들어 있어?" |
| P2 | 질문 정하기 | 보여줄 것 한 가지를 고른다 | "이걸로 뭘 알 수 있어?" |
| P3 | 첫 차트 | 차트 하나를 만든다 | "그걸 그림으로 그려줘" |
| P4 | 다듬기 | 제목·색·주석을 고친다 (2회) | "더 보기 좋게 고쳐줘" |
| P5 | 해석하기 | 세 문장으로 설명한다 | "이 그림이 뭘 말해?" |

프롬프트 틀 (모든 프롬프트 장에 같은 순서로 쓴다)

```
[역할] 너는 ○○ 데이터 분석가야.
[데이터] 올린 파일은 ○○이고, 열은 A, B, C야.
[요청] ○○을 보여주는 ○○ 차트를 HTML 한 파일로 만들어줘.
[조건] 제목은 한국어, 단위 표시, 색은 3가지 이내.
```

프롬프트 번호 규칙: `도시-P3`, `물류-P4-2` (실습-단계-순번)

## 5. 슬라이드 유형별 필수 요소

| 유형 | 필수 요소 |
|---|---|
| 개념 | 한 문장 정의, 그림 1개, 일상 비유 1개 |
| 데이터 | 출처, 기간, 열 풀이(열 이름·뜻·단위) |
| 따라하기 | 화면 캡처, 번호 원형 3개 이내 |
| 프롬프트 | 번호, 도구 칩, 원문 상자, 고쳐 쓸 부분 색 표시 |
| 결과 | 화면 캡처, "여기를 보세요" 표시 1~2곳 |
| 전/후 | 좌우 비교, 바뀐 점 3가지 |
| 확인 | 완성 화면, 확인 항목 3개, 막혔을 때 쓸 문장 |
| 실수 | 틀린 결과, 원인 한 줄, 고친 프롬프트 |

발표자 노트: 모든 장에 말할 내용 2~4문장과 예상 질문 1개를 쓴다.

디자인: `[확정 필요: 기존 강의 덱 스타일 사용 여부]`. 도구 칩 색은 Qwen과 AI Studio를 서로 다른 색으로 고정한다.

## 6. 좋은 차트 기준 (예시 화면과 학생 결과물 공통)

- 제목이 질문에 답한다 (예: "금요일 저녁 6시가 가장 붐빈다").
- 축 이름과 단위가 있다.
- 색은 3가지 이내, 강조할 곳만 진하게.
- 가장 중요한 값 한 곳에 주석이 있다.
- 출처와 기간이 있다.
- 해석은 세 문장: 무엇이 보이는가 → 왜 그럴까(추측임을 밝힘) → 무엇을 하면 좋을까.

## 언어판과 제작 도구 (Genspark)

### 가. 만드는 것
같은 내용의 덱을 **한국어판과 중국어판 두 벌**로 만든다. 두 벌은 서로 다른 폴더에 따로 저장한다. 한 파일에 두 언어를 섞지 않는다.

### 나. 폴더 구조

```
지침서1_스마트시티_물류/
├─ ko/                                  ← 한국어판
│  ├─ 스마트시티_물류_시각화_ko.pptx
│  ├─ 프롬프트모음_ko.txt
│  ├─ data/      (실습 CSV, 열 이름 한국어)
│  └─ captures/  (한국어 프롬프트로 얻은 결과 화면)
└─ zh/                                  ← 중국어판
   ├─ 智慧城市_物流_可视化_zh.pptx
   ├─ 提示词合集_zh.txt
   ├─ data/      (실습 CSV, 열 이름 중국어)
   └─ captures/  (중국어 프롬프트로 얻은 결과 화면)
```

### 다. Genspark 제작 순서
1. **한국어판을 먼저 만든다.** Genspark에 이 지침서 전체를 붙이고 아래 "한국어판 요청문"을 입력한다.
2. 40장 구성표(4절)와 장 번호·제목이 맞는지 확인하고, 틀린 장은 장 번호를 지정해 고친다.
3. PPT 파일(.pptx)로 내려받아 `ko/` 폴더에 넣는다.
4. **중국어판은 새 작업으로 따로 만든다.** 확정된 한국어판과 이 지침서를 함께 주고 "중국어판 요청문"을 입력한다.
5. PPT 파일로 내려받아 `zh/` 폴더에 넣는다.
6. 두 파일을 PowerPoint에서 열어 글자 깨짐, 줄 넘침, 장 수를 확인한다.

※ Genspark의 메뉴 이름과 내려받기 방식은 바뀔 수 있다. 제작 당일 화면을 기준으로 한다.

한국어판 요청문

```
첨부한 지침서를 그대로 따라 강의 슬라이드를 만들어줘.
- 언어: 한국어
- 장 수: 40장 (지침서 4절의 번호·유형·제목을 그대로 사용)
- 대상: 처음 배우는 사람. 지침서 1절의 초보자 원칙을 모두 지켜.
- 프롬프트 장: 원문을 고정폭 글꼴 상자에 넣어.
- 화면 캡처 자리는 "캡처 넣을 곳" 상자로 비워 둬.
- 모든 장에 발표자 노트를 써.
- 편집 가능한 PPT 파일(.pptx)로 내보낼 수 있게 만들어.
```

중국어판 요청문

```
첨부한 한국어 슬라이드와 지침서를 바탕으로 중국어판을 새로 만들어줘.
- 언어: 중국어 간체. 한국어 글자를 한 글자도 남기지 마.
- 장 수, 장 번호, 장 순서, 배치는 한국어판과 똑같이 해.
- 직역하지 말고 중국어권 초보자가 읽기 쉬운 문장으로 써.
- 프롬프트 원문도 중국어로 바꿔. [역할][데이터][요청][조건] 틀은 유지해.
- 데이터 열 이름과 차트 제목·단위도 중국어로 바꿔.
- 발표자 노트도 중국어로 써.
- 편집 가능한 PPT 파일(.pptx)로 내보낼 수 있게 만들어.
```

### 라. 중국어판 규칙
- 글자: 간체를 기본으로 한다. `[확정 필요: 간체/번체]`
- **프롬프트는 번역만 하지 말고 중국어로 Qwen에 실제로 입력해 결과를 다시 확인한다.** 결과 화면 캡처도 중국어 결과로 새로 찍는다.
- 실습 CSV의 열 이름을 중국어로 바꾼 파일을 따로 만든다 (예: `星期`, `时间`, `通行量`).
- 용어는 아래 표로 통일한다. 표에 없는 용어는 추가한 뒤 쓴다.

| 한국어 | 중국어 |
|---|---|
| 데이터 시각화 | 数据可视化 |
| 스마트시티 | 智慧城市 |
| 물류 | 物流 |
| 프롬프트 | 提示词 |
| 차트 | 图表 |
| 선 그래프 | 折线图 |
| 막대 차트 | 柱状图 |
| 히트맵 | 热力图 |
| 파레토 차트 | 帕累托图 |
| 수업용 가상 데이터 | 教学用虚拟数据 |

- 글꼴: 한국어판과 중국어판 모두 해당 언어를 지원하는 글꼴을 쓴다. 중국어판에 한국어 글꼴을 쓰면 글자가 깨진다.
- 중국어는 같은 뜻이라도 글자 수가 줄어든다. 빈자리가 크면 글자 크기를 키우고, 내용을 더 넣지 않는다.
- 도구 접속 안내(11~12번, 37번 장)는 수강생이 있는 지역에서 실제로 접속되는지 확인하고 쓴다. `[확정 필요: 중국어판 수강 대상과 수업 장소]`

## 7. 완성 전 점검표

- [ ] 한국어판은 `ko/`, 중국어판은 `zh/` 폴더에 PPT 파일로 따로 있다.
- [ ] 두 판의 장 수와 장 번호가 같다.
- [ ] 중국어판에 한국어 글자가 남아 있지 않다 (본문·차트·캡처·노트).
- [ ] 중국어 프롬프트를 실제로 입력해 결과를 확인했다.
- [ ] 장 수가 38~42장이다.
- [ ] 모든 프롬프트를 실제로 입력해 결과를 확인했다 (수업 1주일 이내).
- [ ] 화면 캡처가 지금 도구 화면과 같다.
- [ ] 새 용어마다 괄호 풀이가 있다.
- [ ] 프롬프트 장 다음에 결과 장이 있다.
- [ ] 실습마다 "여기까지 됐나요?" 장이 있다.
- [ ] 본문이 5줄을 넘는 장이 없다.
- [ ] 모든 장에 발표자 노트가 있다.
- [ ] 실습 CSV와 프롬프트 모음(txt)을 덱과 함께 나눠 준다.
