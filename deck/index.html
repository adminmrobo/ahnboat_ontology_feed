      처음 보는 말 풀이 (펼치기)
      

        
지시서(지침서)
슬라이드를 만드는 사람이나 AI가 이것 하나만 보고 덱을 만들 수 있게 쓴 작업 문서.

        
md 파일
마크다운(Markdown) 파일. #·|·- 같은 기호로 제목과 표를 표시한 글 파일로, 어떤 AI에도 그대로 첨부할 수 있습니다.

        
덱
슬라이드 한 벌. 강의 한 차시에 쓰는 PPT 파일 하나.

        
프롬프트 사슬
한 번에 끝내지 않고 여러 번 이어 묻는 순서. 예: 데이터 알아보기 → 질문 정하기 → 첫 차트 → 다듬기 → 해석.

        
[확정 필요]
저자(강의자)가 직접 정해야 하는 값. 과목·주차, 데이터셋, 디자인 등.

        
[AI가 채움]
AI가 초안을 써도 되는 자리. ⑤의 지시문으로 한꺼번에 채웁니다.

자세히 만들기 — 하루·시아·모아가 알려 드려요

  

    


    

      
하루어서 오세요, 강의 준비실이에요! 이 도구는 다른 두 도구와 결과물이 달라요. AI에게 "판단"을 받는 게 아니라, AI 슬라이드 도구에게 "강의 덱을 만들어 줘" 하고 맡길 작업 지시서를 만들어요.

      
하루급하면 맨 위 상자에 3~4줄만 써도 지시서가 바로 나와요. 자세히 만들 때는 여섯 단계예요. 아이디어 쓰기 → 강의 틀 정하기 → 언어판·제작 도구 → 지시서 내려받기 → AI로 빈자리 채우기 → 점검. 처음이면 아래 예시 두 개 중 하나를 불러와서 둘러보세요.

      
박사의 메모 · "슬라이드 AI는 지시가 모호하면 예쁜 빈 덱을 만든다. 장 번호·유형·제목을 먼저 정해 주면 내용이 찬 덱을 만든다. 그리고 프롬프트는 반드시 직접 돌려 보고 캡처할 것."

    


    

      
하루시간이 없으면 맨 위 상자에 서너 줄만 쓰세요. 형식은 자유예요. 쓰는 동안 지시서가 저절로 만들어지고, 'md 파일 내려받기'를 누르면 끝이에요.

      
주판봇장 수는 제가 맞춰요! 넘치면 '차트 고르기'·'흔한 실수' 장부터 빼고, 모자라면 넣어요. 실습이 많아서 그래도 넘치면 알려 드릴게요.

      
초파리 연구원빠른 길은 빈자리를 연구실 기본값으로 채워서 바로 쓸 수 있어. 다만 추천 차트와 데이터 열은 기본값이니, 수업 전에 프롬프트를 직접 돌려 보고 ⑥으로 한 번 점검해.

      

    


    

      
모아먼저 강의 아이디어를 편하게 적어 주세요. 누구에게, 무엇을, 어떤 도구로, 몇 장쯤, 어떤 언어로 — 이 다섯 가지가 들어가면 좋아요.

      
모아'아이디어에서 읽어 오기'를 누르면 글에서 장 수·도구 이름·언어·대시보드 여부를 찾아 아래 입력란에 채워 줘요. 아이디어 속 용어는 연구실 개념 지도에서 찾아 용어 풀이 근거로 붙일 수 있어요.

      

    


    

      
시아강의 틀은 두 가지 중에서 골라요. 차트 이어 묻기형은 한 도구로 P1~P5를 이어 물어 차트 하나를 완성하고, 대시보드형은 쉬운 일(Q1·Q2)과 어려운 일(S1~S3)을 두 도구로 나눠요.

      
시아실습은 1~4개까지 넣을 수 있어요. 실습마다 이름, 번호에 붙일 짧은 이름(예: 도시), 질문, 차트를 적어 주세요. 비워 둔 곳은 [AI가 채움]으로 남겨 뒀다가 ⑤에서 AI가 채워요.

      
주판봇입력할 때마다 제가 장 수를 바로 세요! 목표에서 2장 넘게 벗어나면 노란 글씨로 알려 드려요.

      

    


    

      
시아한국어판은 늘 먼저 만들어요. 중국어·영어·일본어판을 고르면 판마다 폴더 구조, 요청문, 용어표가 지시서에 들어가요. 외국어판은 번역만 하지 말고 그 언어로 프롬프트를 실제로 돌려 봐야 해요.

      

    


    

      
하루지시서가 바로 아래에 만들어져요. 'md 파일 내려받기'를 누르면 파일로 저장돼요. 이미 [AI가 채움]이 없으면 그대로 Genspark에 첨부하고, 지시서 안의 '한국어판 요청문'을 붙여 넣으면 돼요.

      

    


    

      
모아[AI가 채움] 자리가 남아 있으면, ⑤의 지시문을 복사해 쓰시는 생성 AI(ChatGPT·Claude·Gemini·Grok·Qwen·DeepSeek·뤼튼 등)에 붙여 넣으세요. 지시서 초안이 지시문 안에 함께 들어 있어서 따로 첨부하지 않아도 돼요. 기존 강의계획서나 교안이 있으면 '참고 자료'로 개요만 첨부하세요. 분량이 A4 2장(약 4,000자) 이내면 전체도 괜찮아요.

      
모아AI가 돌려준 md를 파일로 저장한 다음, 슬라이드 도구로 넘기기 전에 ⑥ 점검 도우미에 한 번 붙여 넣어 보세요.

      

    


    

      
초파리 연구원지시서를 통째로 붙여 넣어. 장 번호가 끊긴 곳, 결과 화면 없이 프롬프트만 이어지는 곳, 확인 장이 빠진 실습, 남은 빈자리를 내가 다 찾아 주지. 다른 사람이 쓴 지시서도 돼.

      
주판봇저는 장 수가 목표 범위 안인지 셀게요! 예시 지시서 ①도 한번 넣어 보세요. 사람이 쓴 지시서에도 고칠 곳이 두 군데 있어요.

어디서 온 형식인가요?
박사가 실제 강의에 쓰려고 만든 지시서 두 벌(예시 ①·②)의 구조를 그대로 따릅니다. 한눈에 보기 → 작성 원칙 → 도구 나누기 → 프롬프트 사슬 → 실습 설계 → 장 구성표 → 유형별 필수 요소 → 좋은 차트 기준 → 언어판·제작 도구 → 점검표 → 확정 필요 항목.

    
슬라이드 AI가 다 해 주나요?
아닙니다. 슬라이드 AI는 구성과 문장을 만들고, 화면 캡처 자리는 비워 둡니다. 프롬프트는 강의자가 수업 1주일 안에 직접 돌려 보고 결과를 캡처해 넣어야 합니다. 도구 화면과 요금은 자주 바뀌므로 "수업일 기준"으로 적습니다.
