[개념] 이름 (유형) — 정의 [출처 페이지 기호#위치]
- 정규화 (개념) — 다르게 쓴 표현을 하나의 형태로 통일하는 일. [p4#m4]
- 트랜스포머 (개념) — 어텐션으로 문장의 모든 단어를 한 번에 보고 관계를 계산하는 신경망 구조(8회차). [p4#nnote]
- 기울기 소실 (용어) — 긴 순서를 거꾸로 거치며 학습 신호가 거듭 곱해져 사라지는 현상. [p2#g-기울기소실]
- 학습률 (용어) — 새 나무의 예측을 반영하는 배수. [p3#g-학습률]
- 데이터 누수 (개념) — 예측 시점에 알 수 없는 정보가 입력에 들어간 상태. [p4#g-데이터누수]
- 정확도 (지표) — 맞힌 비율. 불균형 데이터에서 속기 쉽다. [p1#pm-cap]
- 퍼셉트론 (방법) — 여러 입력에 가중치를 곱해 더하고 편향을 더한 뒤 시그모이드로 0~1 확률로 바꾸는 뉴런 하나. [p1#top]
- SVM (방법) — 두 클래스 사이 여백(마진)이 가장 넓은 경계를 찾는 분류 알고리즘. [p6#race]
- 표준화 (개념) — 비교 전에 상관없는 차이(단위·자리·크기)를 없앤다. [p1#practice]
- 가중합 (개념) — 입력마다 가중치를 곱해 더한 값. z = w·x + b. [p1#g-가중합]
- 프롬프트 (개념) — AI에게 무엇을 만들지 알려 주는 글. [p1#prompt]
- 표준편차 (개념) — 데이터가 평균에서 보통 얼마나 떨어져 있는지 나타내는 폭. 표준화의 한 눈금. [p4#m4]
- 로지스틱 회귀 (다항) (방법) — 정답별 점수 → 소프트맥스 → 확률 [p1#practice]
- 서포트 벡터 (용어) — 경계 가까이 있어 경계 위치를 결정하는 데이터 점. [p6#g-서포트벡터]
- CNN (후배, 6-4) (방법) — 작은 필터가 이웃 칸을 함께 보는 합성곱 신경망. 같은 시험지에서 봉인 97.6%를 기록한 6-4의 후배다. [p4#nnote]
- ReLU (방법) — 0보다 작은 값을 0으로 바꾸는 규칙. f(x) = max(0, x). [p1#practice]
- MLP (방법) — 분류 모델과 성적표 [p2#am-cap]
- 소프트맥스 (개념) — 점수 여러 개를 합이 1인 확률로 [p2#g-소프트맥스]
- 은닉층 (용어) — 입력과 출력 사이의 층. 입력을 새 좌표(특성)로 바꾼다. [p2#smout]
- 다층 퍼셉트론 (방법) — 입력과 출력 사이에 은닉층을 끼워 굽거나 띠 모양인 경계도 만드는 모델. [p2#xor-cap]
- 손실 (개념) — 그린 그림과 정답이 얼마나 다른지 나타내는 숫자. 이 페이지에서는 픽셀 차이의 제곱 평균. [p3#m3]
- 시험 정확도 (지표) — 학습에 쓰지 않은 데이터를 맞힌 비율. [p1#pm-cap]
- 활성화 함수 (개념) — 가중합을 비선형으로 바꾸는 함수. 시그모이드, tanh, ReLU 등이 있고, 없으면 층을 쌓아도 직선 하나와 같다. [p1#pupd]
- 편향 (개념) — 가중합에 더하는 값. 얼마나 쉽게 반응할지를 정한다. [p1#g-편향]
- 기울기 (개념) — 변수를 아주 조금 바꿨을 때 손실이 얼마나 변하는지. 손실을 줄이려면 기울기 반대쪽으로 고친다. [p1#dataset]
- 시그모이드 (개념) — 점수를 0~1 사이 확률로 바꾸는 함수. [p2#g-시그모이드]
- 은닉 뉴런 (용어) — 은닉층의 한 칸. 입력의 가중합에 비선형 함수를 씌운 값 하나를 낸다. [p2#xor]
- 경사하강 (용어) — 손실이 줄어드는 방향으로 가중치를 조금씩 옮기는 최적화 방법. [p3#top]
- 규제 (개념) — 계수에 벌점을 줘 0 쪽으로 당기기. [p4#nnote]
- 정규화 (개념) — 모델이 너무 복잡해지지 않게 벌점을 주는 방법. (표준화·정규분포와 다른 뜻) [p1#top]
- tanh (용어) — 값을 −1과 1 사이로 눌러 주는 함수. 후보 내용(g)과 은닉 상태에 쓴다. [p2#afinfo]
- 시험 데이터 (용어) — 학습에 쓰지 않고 채점에만 쓰는 데이터. [p4#m4]
- 경사하강법 (방법) — 예측 → 오차 → 책임 나누기 → 반대 방향으로 조금 옮기기를 반복한다. [p3#top]
- 계단 함수 (개념) — 값이 뚝뚝 끊겨 바뀌는 함수. 디딤판에서 기울기 0. [p1#m1]
- 평균 (개념) — 모든 값을 더해 개수로 나눈 값. 데이터의 가운데를 나타냄. [p4#nnote]
- 확률 (개념) — 어떤 일이 일어날 가능성을 0과 1 사이의 숫자로 나타낸 것. [p6#kind]
- 비용함수(로그 손실) (개념) — 요소가격과 산출이 주어졌을 때의 최소비용. [p1#top]
- 에포크 (개념) — 훈련 데이터 전체를 한 번 다 보기. [p1#pm-cap]
- SPLIT (방법) — 구분기호로 문자열을 여러 셀에 나눠요. [p1#dataset]
- 활성화 함수(시그모이드·ReLU) (개념) — 신경망에 쓰는 비선형 함수. 시그모이드 치역 0~1 [p2#m2]
- GELU (방법) — z × 통과 비율(정규분포 누적). 최저 약 −0.17. [p2#afinfo]
- Leaky ReLU (방법) — 음수 쪽에 0.01배를 흘리는 ReLU. [p2#afinfo]
- 미니배치 (용어) — 한 걸음에 쓰는 샘플 묶음. 훈련 데이터를 처음부터 끝까지 한 번 다 돌면 1에포크다. [p3#gm-cap]
- 평균제곱오차 (개념) — 회귀의 손실. (예측 − 정답)²의 평균. [p3#g-평균제곱오차]
- MSE (개념) — 평균 제곱 오차. 큰 오차에 민감. [p3#m3]
- 배치 크기 (개념) — 기울기를 계산할 때 보는 데이터 수. [p4#nnote]
- 등고선 (개념) — 높이(목표 값)가 같은 점을 이은 선. [p4#m4]
- 상태 (개념) — 지금까지 읽은 것을 요약한 64칸짜리 숫자 묶음 h. 걸음마다 새로 계산되어 덮어써진다. [p6#read]
- 확률분포(정규·포아송·지수·균등·이항) (개념) — 데이터 모양의 이름표. 확률 = 넓이 [p6#kind]
- 정규분포 (개념) — 종 모양 분포. 비율 추정에서 모집단이 이 모양일 필요는 없다. [p6#g-정규분포]

[개념] 이름 (유형) — 정의 [출처 페이지 기호#위치]
- 언어 모델 (개념) — 단어의 순서(시퀀스)에 확률을 할당하는 모델. 다음 단어 예측과 문장의 그럴듯함 판정에 쓴다. [p5#insE]
- RNN (용어) — 순환 신경망. 이전 은닉 상태를 다음 시점에 넘기며 순서를 처리. [p7#rnn]
- 은닉 상태 (용어) — RNN이 지금까지 읽은 내용을 담아 다음 시점에 넘기는 벡터. [p7#rnn]
- LSTM (용어) — 셀 상태와 망각·입력·출력 게이트로 장기 기억을 지키는 RNN. [p6#compare]
- 셀프 어텐션 (개념) — 같은 문장 안의 모든 단어가 서로를 Q·K·V로 보는 어텐션. [p8#self]
- GPT (용어) — 생성형 사전훈련 트랜스포머. 디코더로 다음 단어를 차례로 예측. [p8#family]
- BERT (용어) — 양방향 인코더 모델. 가린 단어를 앞뒤 문맥으로 맞히며 사전훈련. [p8#family]
- 과적합 (개념) — 학습 데이터의 잡음까지 외운 상태. [p2#fit]
- 재현율 (지표) — 실제 불량 중 잡은 비율. [p9#a3-2]
- 시계열 (개념) — 시간 순서대로 쌓인 측정값. [p4#author]
- 최대 풀링 (방법) — 구역마다 가장 큰 값 하나만 남기는 요약. [p3#pool]
- 파라미터 수 (개념) — 학습으로 바뀌는 숫자의 개수. 합성곱 층 (Kh·Kw·Cin + 1)·Cout, 완전연결층 (nin + 1)·nout. [p9#a3-7]
- 버섯체 (생물 대응) — 많은 입력을 모아 더하고 문턱을 넘으면 신호를 낸다. 단, 진짜 뉴런은 스파이크로 일한다. [p1#cInfo]
- 활성함수 (용어) — 더한 신호를 꺾어 다음 층으로 넘기는 함수(ReLU, 시그모이드 등). 이것이 있어야 곡선 경계를 그릴 수 있다. [p2#act]
- 손실 함수 (개념) — 예측이 정답과 얼마나 다른지 숫자 하나로 잰 것. 회귀는 평균 제곱 오차, 분류는 교차 엔트로피를 쓴다. 학습은 이 숫자를 줄이는 일이다. [p2#loss]
- SGD (확률적 경사하강법) (방법) — 일부(배치)로 기울기를 계산해 자주 고치는 경사하강법. [p2#opt]
- Adam (방법) — 걸음 크기를 기울기의 크기에 맞춰 알아서 조절하는 경사 하강법. [p2#opt]
- 드롭아웃 (개념) — 학습 때 신경망의 일부를 무작위로 꺼서 과적합을 막는 장치. [p2#insF]
- 교차 엔트로피 (용어) — 분류의 손실. 정답 칸의 예측 확률에 −log를 씌워, 확신하고 틀릴수록 크게 벌한다. [p2#insL]
- 조기 종료 (방법) — 검증 손실이 다시 오르기 전에 학습을 멈추는 방법 [p2#insF]
- 대시보드 (개념) — 정의 없음 [p3#teach]
- 가중치 공유 (개념) — 같은 계산(필터)을 모든 위치에 반복해 쓰는 것. [p3#analogy]
- 평균 풀링 (방법) — 구역마다 평균을 남기는 요약. [p3#pool]
- 양자화 (방법) — 가중치를 2ᵇ개 눈금 중 가장 가까운 값으로 [p4#quant]
- 스펙트로그램 (용어) — 소리를 시간×높낮이로 펼친 그림 [p4#mel]
- 데이터 과학(귀납) (개념) — 데이터를 탐색해 패턴을 찾고 가설을 끌어내는 방식. 데이터 과학의 특징. [p4#author]
- 창 길이 (lookback) (개념) — 거슬러 보는 과거 날 수. 이 페이지의 “창 길이”. 창에 들어가는 날 수. 이 페이지의 모델에서는 기억의 길이와 같다. [p4#series]
- 임베딩 (개념) — 그림·글을 의미가 담긴 짧은 숫자 묶음으로 바꾼 것. [p5#embed]
- 위치 정보 (개념) — 정의 없음 [p5#order]
- 벡터 (개념) — 숫자 한 줄. 데이터 한 행, 가중치, 임베딩 [p5#series]
- 후보 (용어) — 이번 걸음에 셀 상태에 적을 새 내용. tanh로 −1~1 사이 값이다. [p6#author]
- 게이트 (용어) — 정보를 얼마나 통과시킬지 0~1 사이로 정하는 문. LSTM·GRU가 기억을 고를 때 쓴다. [p7#insG]
- GRU (6-8) (방법) — LSTM과 같은 목적의 더 간단한 후배. 이 편에서는 이름만 나온다. [p7#gru]
- 오토인코더 (방법) — 그림을 숫자 몇 개로 접었다 펴서, 넣은 그림 자신을 맞히도록 배우는 신경망. [p7#ae]
- 셀 상태 (용어) — LSTM의 장기 기억 줄. 게이트가 지우고 더하며 시점마다 다음으로 넘긴다. [p7#lstm]
- LSTM·GRU (방법) — 게이트로 기억을 얼마나 지우고 쓰고 꺼낼지 정하는 순환 신경망. GRU는 게이트가 둘이라 LSTM보다 가볍다. [p7#run1]
- 병목 (개념) — 상자 가운데 가장 좁은 층. 접은 지도. [p7#analogy]
- 입력 게이트 (용어) — 새 후보 내용(g)을 셀 상태에 얼마나 더할지 정하는 문. [p7#insL]
- 파라미터 (개념) — 학습으로 정해지는 값(계수·가중치). ①층위. [p7#series]
- 인코더 (방법) — 입력 64칸을 병목 값으로 줄이는 쪽. 이 편은 64-128-32-k 구조다. [p8#family]
- 검증 손실 (지표) — 정의 없음 [p9#a3-2]

- 모델 생물로서의 초파리 (개념) — 전체 배선도가 공개되어 있고, 감각에서 행동까지 길이 짧으며, 원하는 뉴런만 켜고 끌 수 있어 신경망을 배우기에 알맞은 크기의 동물이다. [p1#why]
- 커넥톰 (개념) — 뇌 전체의 뉴런과 연결을 담은 배선도. 신경망으로 치면 모델의 구조와 연결 전체다. [p1#why]
- 스파이크 (개념) — 뉴런 막의 전압이 문턱을 넘을 때 나가는 크기가 일정한 전기 펄스. [p1#elec]

- 시냅스 (개념) — 뉴런 사이 틈에서 전기가 신경전달물질로 바뀌어 건너가는 곳. 전달 효율이 가중치다. [p1#elec]
- 연속 전압 신호 (개념) — 짧은 거리만 신호를 보내는 뉴런이 스파이크 대신 전압을 연속으로 오르내리며 전하는 방식. [p1#elec]

- 역합성곱 신경망 (방법) — DCN을 거꾸로 돌린다. 작은 정보에서 큰 이미지를 펼쳐 낸다. [p1#m-deconv-net]
- 합성곱 역그래픽스망 (방법) — 합성곱 인코더 + 확률 잠재층 + 역합성곱 디코더. 사실상 이미지용 VAE다. [p1#m-dcign]
- 생성·특수 구조 (개념) — 학습 방식이나 연결 방식이 독특한 구조들입니다. 원본 차트에서 한 묶음으로 실렸습니다. [p1#a6]
- 액체 상태 기계 (방법) — 스파이크를 내는 셀을 무작위로 엉성하게 연결해 두고, 출력층만 학습한다. [p1#m-lsm]
- 극단 학습 기계 (방법) — 은닉층 가중치를 무작위로 정해 고정하고, 출력층만 한 번에 계산해서 끝낸다. [p1#m-elm]
- 에코 상태 네트워크 (방법) — 무작위로 연결된 순환 셀 덩어리(저수지)를 고정해 두고 출력층만 학습하는 RNN. [p1#m-esn]
- 깊은 잔차 신경망 (방법) — 몇 층마다 입력을 건너뛰어 더해 주는 지름길을 달았다. 그래서 수백 층도 학습된다. [p1#m-deep-residual-network]
- 코호넨 네트워크 (방법) — 정답 없이 비슷한 입력끼리 지도 위 가까운 칸에 모이게 정리한다(자기조직화 지도). [p1#m-kohonen-network]
- 신경 튜링 머신 (방법) — 신경망에 외부 메모리(아래 파란 셀)를 붙여 어텐션으로 읽고 쓰게 했다. 알고리즘을 배우려는 시도다. [p1#m-ntm]
- 가중치 (용어) — 입력 신호에 곱하는 숫자. 클수록 그 입력을 더 중요하게 본다. 초파리로 치면 시냅스 전달 세기에 해당한다. [p1#guide]
- 역전파 (용어) — 출력의 오차를 거꾸로 흘려 각 가중치를 얼마나 고칠지 계산하는 방법. 초파리 뇌는 쓰지 않는 것으로 여겨진다. [p1#a5]
- 손실함수 (용어) — 모델이 얼마나 틀렸는지를 숫자 하나로 재는 함수. 학습은 이 값을 줄이는 과정이다. [p1#guide]
- 합성곱 (용어) — 작은 창(커널)을 이미지 위로 밀며 같은 가중치로 이웃 픽셀을 묶어 계산하는 연산. [p1#hero]
- 어텐션 (용어) — 모든 위치끼리 관련 점수를 매기고 그 점수만큼 정보를 섞는 계산. 이름만 사람의 주의에서 빌렸다. [p1#a6]
- 커넥톰 (용어) — 뇌의 뉴런과 시냅스 연결을 모두 적은 배선도. 구조일 뿐, 시냅스 세기와 뉴런 성질은 따로 필요하다. [p1#kg]
- 시냅스 (용어) — 뉴런과 뉴런이 신호를 주고받는 접점. [p1#a1]
- 어텐션 계열 (개념) — 모든 위치가 서로를 얼마나 참고할지 점수를 매겨, 먼 곳도 한 번에 봅니다. 2017년 이후 가장 큰 변화입니다. [p2#b1]
- 전문가 혼합 (방법) — 전문가 망 여러 개를 두고, 길잡이(라우터)가 입력마다 몇 명만 골라 일을 시킨다. [p2#m-moe]
- 순환의 새 갈래 (개념) — 순환 신경망의 장점(작은 상태로 계속 갱신)은 살리고 약점(먼 과거를 잊음, 느린 학습)을 고치려는 구조들입니다. [p2#b2]
- 액체 시상수 망 (방법) — 뉴런마다 반응 속도(시상수)가 입력에 따라 바뀐다. 아주 작은 망으로도 연속 신호를 다룬다. [p2#m-ltc]
- 신경 상미분방정식 (방법) — 층을 한 칸씩 쌓는 대신, 상태가 시간에 따라 연속으로 흐르는 방정식으로 본다. [p2#m-neural-ode]
- 이미지와 생성의 새 도구 (개념) — 픽셀 단위로 정확히 칠하거나(U-Net), 잡음에서 그림을 만들거나(확산), 부분과 전체의 배치를 지키려는(캡슐) 구조들입니다. [p2#b3]
- 유넷 (방법) — 줄이는 길과 키우는 길을 U자로 잇고, 같은 높이끼리 지름길을 놓아 세부를 살린다. [p2#m-u-net]
- 확산 모델 (방법) — 그림에 잡음을 조금씩 더하는 과정을 배운 뒤, 거꾸로 잡음을 한 걸음씩 걷어 내며 새 그림을 만든다. [p2#m-diffusion-model]
- 정규화 흐름 (방법) — 되돌릴 수 있는 변환을 여러 번 겹쳐, 단순한 분포를 복잡한 분포로 정확히 바꾼다. [p2#m-normalizing-flow]
- 캡슐 네트워크 (방법) — 뉴런 하나 대신 '캡슐'이 방향과 크기를 가진 벡터를 낸다. 부분과 전체의 배치를 보존하려 한다. [p2#m-capsule-net]
- 구조를 다루는 망 (개념) — 점과 선으로 된 데이터를 그대로 다루거나(GNN), 연결선 자체를 배울 수 있는 함수로 바꿉니다(KAN). [p2#b4]
- 그래프 신경망 (방법) — 점과 선으로 된 그래프에서, 이웃끼리 메시지를 주고받으며 각 점의 표현을 고친다. [p2#m-gnn]
- 콜모고로프-아르놀트 망 (방법) — 가중치 숫자 대신 연결선마다 '배울 수 있는 곡선 함수'를 둔다. 학습 결과를 식으로 읽어 내기 쉽다. [p2#m-kan]
- 뇌에서 배선을 빌린 망 (개념) — 뉴런이 전압을 쌓다 스파이크로 터지는 방식을 그대로 쓰고, 마지막에는 실제 초파리 배선도로 만든 모형까지 봅니다. [p2#b5]
- 스파이킹 신경망 (방법) — 뉴런이 막 전압을 쌓다 문턱을 넘으면 짧은 스파이크를 낸다. 신호가 있을 때만 계산해 에너지를 아낀다. [p2#m-snn]
- 배선 제약 시각망 (방법) — 초파리 시각계 배선도로 연결을 고정하고, 모르는 값(시냅스 세기 등)만 학습해 움직임 감지를 맞췄다. [p2#m-connectome-constrained]
- 초파리 커넥톰 뇌 모형 (방법) — 수컷 초파리 중추신경계 배선도를 연결 행렬로 쓰고, 뉴런을 누설 적분 발화 식으로 돌린다. 학습한 가중치는 0개다. [p2#m-fly-connectome-lif]
- 잠재공간 (용어) — 데이터를 압축해 놓은 좌표 공간. 이 좌표를 옮기면 생성되는 결과가 바뀐다. [p2#b3]
- 스파이크 (용어) — 뉴런의 막 전압이 문턱을 넘을 때 나오는 짧은 전기 신호. [p2#b5]
- 누설 적분 발화 (용어) — 입력을 전압으로 쌓되 조금씩 새어 나가게 하고, 문턱을 넘으면 발화하는 뉴런 식. [p2#b5]
- 임베딩 (용어) — 토큰이나 패치를 여러 숫자로 된 좌표로 바꾼 것. 비슷한 뜻은 가까운 좌표가 된다. [p2#b1]
- 초파리 로봇 사양표 (개념) — ATK·HIT(판단값)와 SPD·EN·MEM(규칙값) 다섯 능력치로 신경망을 비교하는 설명용 표. [p3#r1]
- ATK 공격력 (개념) — 표현력. 판단값. [p3#r1]
- HIT 명중률 (개념) — 실전 정확도(학습을 마친 모델이 처음 보는 입력을 맞히는 정도). 판단값. 명중 확률 = 0.5 + 0.1 × HIT. [p3#r1]
- SPD 기동력 (개념) — 새 입력 하나에 답하기까지의 계산 단계. 규칙값. [p3#r2]
- EN 효율 (개념) — 공격 1회 소모 EN을 정하는 계산 규모. 규칙값. [p3#r2]
- MEM 기억 (개념) — 시간 기억 방식. 규칙값. [p3#r2]
- 전원 체급 (개념) — 초파리 몸 60, 드론 200, 노트북 600, 서버(제한 없음) 네 단계의 설명용 전원 조건. [p3#r4]
- 초파리 몸 60 EN (개념) — 정의 없음 [p3#r4]
- 드론 200 EN (개념) — 정의 없음 [p3#r4]
- 노트북 600 EN (개념) — 정의 없음 [p3#r4]
- 서버 (제한 없음) (개념) — 정의 없음 [p3#r4]
- 체급별 공통 보스 적합도 (총 피해 ÷ 보스 HP) (지표) — 공통 보스에게 준 총 피해를 HP 200으로 나눈 설명용 지표. [p3#r3]
- 뉴로모픽 (용어) — 스파이크가 날 때만 계산하도록 만든 뇌 모방 반도체. 같은 일을 적은 전력으로 한다. [p3#r2]
- 한 방향으로 흐르는 망 (개념) — 신호가 입력에서 출력으로 한 방향으로만 흐른다. 모든 신경망의 출발점이다. [p4#hangar]
- 공간을 보는 망 (개념) — 작은 창으로 이웃한 픽셀끼리만 묶어 본다. 같은 창을 화면 전체에 재사용한다. [p4#hangar]
- 시간을 기억하는 망 (개념) — 앞 시점의 상태를 다음 시점에 다시 넣는다. 순서가 있는 데이터를 다룬다. [p4#hangar]
- 필요한 곳을 직접 보는 망 (개념) — 모든 위치가 서로를 얼마나 참고할지 점수를 매겨, 먼 곳도 한 번에 본다. [p4#hangar]
- 압축하고 만들어 내는 망 (개념) — 데이터를 좁은 통로로 압축하거나, 잡음에서 새 데이터를 만들어 낸다. [p4#hangar]
- 에너지로 기억을 찾는 망 (개념) — 층 구분 없이 서로 연결되어, 가장 안정한 상태로 굴러가며 기억을 떠올린다. [p4#hangar]
- 뇌에서 배선을 빌린 망 (개념) — 뉴런이 전압을 쌓다 스파이크로 터진다. 마지막에는 실제 초파리 배선도로 만든 모형까지 본다. [p4#hangar]

- Word2Vec (방법) — 주변 단어를 예측하는 작은 신경망을 학습해 단어마다 100~300차원의 밀집 벡터를 얻는 단어 임베딩 방법. 분포 가설에 바탕을 둔다. [p5#lv4]
- 분포 가설 (개념) — 비슷한 문맥에 등장하는 단어는 비슷한 의미를 가진다는 가설(J.R. 퍼스). [p5#lv4]
- 코사인 유사도 (개념) — 두 벡터가 이루는 각도의 코사인. −1(반대)~1(같은 방향) 값을 가지며 벡터의 길이는 무시한다. [p5#lv3]
- 원-핫 인코딩 (방법) — 범주를 0/1 열들로 바꾸는 방법. [p5#lv2]
- 채널 (개념) — 포개 놓은 판의 장 수. 돋보기 개수만큼 무늬 지도가 생긴다. [p1#lv4]
- 주성분 (개념) — 자료가 가장 크게 출렁이는 방향. 차례로 직각. [p2#lv3]
- 패딩(덧대기) (개념) — 입력 둘레에 0을 덧대는 것. [p2#lv2]
- 공변미분 (개념) — 숫자(성분) 변화에서 눈금이 돈 몫을 빼고 남은 진짜 변화. ∇ = ∂ + Γ. [p4#deep]
- 계량 (개념) — 그 자리에서 길이와 각도를 재는 자 눈금 규칙. [p4#deep]
- 특성공학(PolynomialFeatures) (개념) — 원시 데이터에서 모델이 더 잘 배우도록 특성을 새로 만들거나 바꾸는 과정. [p6#lv1]
- 흑백 변환 (가중 평균) (방법) — 0.299R + 0.587G + 0.114B [p2#duel]
- 겹침 점수(내적)와 각도 (개념) — 같은 자리끼리 곱해 더한 값. cos θ로 방향의 닮음을 잰다 [p5#lv3]
- 기준 모델 (개념) — 큰 모델과 비교할 단순한 출발 모델 (TF-IDF + 로지스틱 회귀) [p6#lv2]
- 행렬 — 데이터를 담는 표 (개념) — 가로줄 = 샘플, 세로줄 = 특성. 모양 m × n [p1#lv3]
- 선형대수 (개념) — 벡터·행렬과 그 변환을 다루는 수학. 텐서는 그 연장선에 있다. [p1#why]
- 스칼라 (개념) — 축이 없는 숫자 하나. 0차 텐서. [p1#lv1]
- 텐서 (개념) — 축이 여러 개인 숫자 묶음. 이 페이지에서는 데이터·코드에서 쓰는 '다차원 배열'의 뜻으로 쓴다. [p1#lv4]
- 차수(축의 개수) (개념) — 텐서의 원소 하나를 가리키는 데 필요한 인덱스 개수. 코드에서는 ndim. [p1#big]
- 축 (개념) — 숫자가 늘어서는 한 방향. 축마다 이름(행, 열, 채널, 묶음)을 붙여 읽는다. [p1#big]
- 인덱스 (개념) — 원소 하나의 위치를 가리키는 번호. 0부터 센다(코드 기준). [p1#lv2]
- 모양(shape) (개념) — 축마다 길이를 적은 목록. 예: (6, 8, 3). [p1#lv5]
- 원소 (용어) — 텐서 안의 숫자 한 칸. 원소 수는 shape의 곱. [p1#big]
- 슬라이스 (개념) — 한 축의 인덱스를 고정해 꺼낸 더 낮은 차수의 조각. [p1#lv4]
- 배치(묶음) (개념) — 같은 모양의 데이터 여러 개를 맨 앞 축으로 쌓은 묶음. [p1#lv5]
- 모양 바꾸기(reshape) (방법) — 원소 개수는 그대로 두고 shape만 바꾸는 연산. 축 순서 약속이 맞아야 같은 데이터로 돌아온다. [p1#duel]
- 축 이름표 지키기 (방법) — 펴기와 접기에 같은 축 순서(예: 높이·너비·채널)를 쓰는 방법. [p1#duel]
- 순서 모르고 접기 (방법) — 펼 때와 다른 축 순서(채널·높이·너비)로 다시 접는 방법. [p1#duel]
- rank (두 가지 뜻) (용어) — 인포그래픽이 말하는 rank는 축의 개수(차수)이고, 행렬의 rank는 독립인 열의 개수다. 이 페이지는 '차수'로 통일한다. [p1#sum]
- 픽셀 일치율 (지표) — 되돌린 그림에서 세 채널 값이 원본과 모두 같은 픽셀의 비율. [p1#duel]
- 장난감 하트 그림 6×8×3 (데이터) — 이 페이지가 만든 설명용 컬러 그림 텐서. 실제 데이터 아님. [p1#lv4]
- 컬러 그림은 흔히 높이×너비×채널로 담는다 (개념) — 정의 없음 [p1#lv4]
- 차수×분야 좌표판 (개념) — 차수 0~4와 네 분야로 텐서의 쓰임을 정리한 표. [p2#big]
- 축 이름 (개념) — 축에 붙이는 뜻(매장, 토큰, 변수). shape보다 쓰임을 잘 알려 준다. [p2#why]
- 축 따라 합치기(피벗) (방법) — 한 축을 따라 더해 그 축을 없애는 연산. 차수가 하나 준다. [p2#lv1]
- 판매 큐브 (5, 4, 6) (데이터) — 매장×상품×월 설명용 데이터. [p2#lv1]
- 임베딩 텐서 (개념) — (문장, 토큰, 차원) 모양으로 단어 벡터를 쌓은 텐서. [p2#lv2]
- 공분산 행렬 (개념) — 변수 짝마다 함께 움직이는 정도를 담은 대칭 2차 텐서. [p2#lv3]
- 3·4차 적률 텐서 (개념) — 비대칭·두꺼운 꼬리 정보를 담는 (n,n,n), (n,n,n,n) 텐서. [p2#lv3]
- 좌표 변환 규칙(텐서의 물리적 정의) (개념) — 좌표를 바꿀 때 성분이 정해진 규칙으로 바뀌고 대상 자체는 그대로인 것. [p2#lv4]
- 응력 텐서 (개념) — 물체 속 한 점의 면마다 걸리는 힘을 담은 2차 텐서. [p2#lv4]
- 컬러 축 유지 (방법) — (6,6,3) 세 축을 그대로 쓴다. [p2#duel]
- 빨강·초록 사과 40장 (데이터) — 밝기가 거의 같은 빨강·초록 사과 설명용 그림. [p2#duel]
- 물리·수학의 텐서는 좌표 변환 규칙으로 정의된다 (개념) — 정의 없음 [p2#lv4]
- 축약 (개념) — 두 텐서의 같은 축을 따라 곱해 더해 그 축을 없애는 연산. [p3#big]
- 원소별 연산과 브로드캐스트 (방법) — 같은 자리끼리 계산하고, 모양이 다르면 뒤 축부터 맞춰 늘려 붙인다. [p3#lv1]
- 행렬 × 벡터 (방법) — y = Ax. x의 축이 A의 둘째 축과 축약된다. [p3#lv2]
- 행렬곱 (방법) — (m,n)(n,p)→(m,p). 가운데 축 n이 축약된다. [p3#lv3]
- 전치·축 바꾸기·reshape (방법) — 읽는 순서를 바꾸거나(permute), 순서를 두고 모양만 바꾼다(reshape). [p3#lv4]
- einsum (아인슈타인 표기) (방법) — 축 이름 글자로 연산을 적고, 오른쪽에 없는 글자를 곱해 더해 없앤다. [p3#lv5]
- 행렬식 det (개념) — 면적·부피 배율. 0이면 역행렬이 없다. [p3#lv2]
- 곱하는 순서와 비용 (개념) — 결합법칙으로 결과는 같지만 곱셈 횟수가 달라진다. [p3#lv3]
- 외적 (개념) — 사라지는 축 없이 차수가 더해지는 곱. 텐서 분해의 재료. [p3#lv5]
- 내적 (개념) — 두 벡터를 축약해 스칼라를 얻는 곱. [p3#lv5]
- 메모리 순서 (개념) — 숫자를 한 줄로 저장한 순서. reshape은 이 순서를 유지한다. [p3#lv4]
- 반복문으로 한 칸씩 (방법) — 칸마다 한 단계씩 계산. [p3#duel]
- 벡터화(텐서 연산 한 줄) (방법) — 여러 칸을 한 번에 계산. [p3#duel]
- 계산 단계 수 (지표) — 256칸 동시 처리 가정에서 걸린 단계 수. [p3#duel]
- 아인슈타인 합 규약 (개념) — 한 항에 같은 인덱스가 두 번 나오면 그 인덱스로 더한다는 표기 약속. [p3#lv5]
- 벡터화 단계 수 모형(256칸 동시 처리 가정) (개념) — 정의 없음 [p3#duel]
- 고유벡터와 고윳값 (개념) — Av = λv. 방향은 그대로, 길이만 λ배. [p4#lv1]
- 특이값 분해(SVD) (방법) — 행렬을 σ·u⊗v 층의 합으로 쪼갠다. 큰 σ부터 k개면 rank k 근사. [p4#lv2]
- CP 분해 (방법) — 3차 이상 텐서를 벡터 외적 R개의 합으로 근사한다. [p4#lv3]
- 교대 최소제곱(ALS) (방법) — 한 축씩 번갈아 최소제곱으로 푸는 CP 계산법. [p4#lv3]
- 기울기 텐서 (개념) — 가중치와 같은 모양의 기울기. 모든 칸을 한 번에 고친다. [p4#lv5]
- 행렬의 rank (개념) — 0이 아닌 특이값의 개수. [p4#lv2]
- 텐서의 rank (CP rank) (개념) — 원래 텐서를 만드는 데 필요한 최소 외적 조각 수. [p4#lv3]
- 저랭크 근사 (개념) — 큰 σ 몇 층만으로 행렬을 근사. [p4#lv2]
- 공변·반변 (개념) — 좌표 눈금 변화에 반대로/같이 바뀌는 성분, 아래·위 첨자. [p4#deep]
- 응력-에너지 텐서 (개념) — 에너지·운동량·압력·응력을 담은 (4,4) 대칭 텐서. [p4#deep]
- 텐서 대수 (개념) — 모든 차수를 모으고 외적을 곱으로 하는 대수. [p4#deep]
- 작은 학습률 0.02 (방법) — 정의 없음 [p4#duel]
- 큰 학습률 0.09 (방법) — 정의 없음 [p4#duel]
- 20걸음 뒤 오차 (지표) — 정의 없음 [p4#duel]
- 캐릭터 인기 텐서 (4, 3, 4) (데이터) — 표정×복장×행동, 취향 2개 + 잡음으로 만든 설명용 데이터. [p4#lv3]
- 정수 번호 인코딩 (방법) — 단어마다 정수 하나를 붙이는 가장 단순한 변환. [p5#lv1]
- 손으로 정한 좌표 (3축 임베딩) (방법) — 사람이 정한 축(성별·지위·나이)에 단어마다 좌표를 주는 방법. 이 페이지의 설명용 예시. [p5#lv3]
- 문맥에서 배운 임베딩 (방법) — 단어와 주변 말의 동시출현에서 좌표를 계산해 얻는 임베딩. [p5#lv4]

- 음수 표본 skip-gram (방법) — 가운데 단어로 주변 단어를 맞히도록 학습하되, 무작위 음수 표본과 구별하게 하는 word2vec 학습법. [p5#lv4]
