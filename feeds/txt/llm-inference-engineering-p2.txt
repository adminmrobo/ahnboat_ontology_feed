- 자연어 처리 모델의 발전 (개념) — 규칙 기반에서 통계 기반(N-gram), 단어 임베딩, 순환 신경망, 어텐션·트랜스포머, 대규모 언어모델로 이어진 자연어 처리 모델의 흐름. [p6#lv1]
- 언어 모델 (개념) — 단어의 순서(시퀀스)에 확률을 할당하는 모델. 다음 단어 예측과 문장의 그럴듯함 판정에 쓴다. [p6#lv2]
- 통계 기반과 딥러닝 기반 언어 모델 (개념) — 빈도·확률로 단어 순서를 모델링하는 통계 기반(N-gram, HMM, 최대 엔트로피)과 신경망으로 문맥을 학습하는 딥러닝 기반(RNN, LSTM, Transformer, BERT, GPT, T5)… [p6#lv3]
- 자연어 처리 (개념) — 사람의 언어를 컴퓨터가 처리하는 기술(NLP). [p6#lv1]
- 트랜스포머 (개념) — 어텐션으로 문장의 모든 단어를 한 번에 보고 관계를 계산하는 신경망 구조(8회차). [p6#lv1]
- N-gram (개념) — 연속된 단어 N개 묶음의 빈도로 다음 단어 확률을 구하는 통계 모델. [p6#lv2]
- 평활 (개념) — 본 적 없는 조합의 확률이 0이 되지 않게 횟수에 작은 수를 더하는 방법. [p6#lv2]
- 희소성 (용어) — 가능한 단어 조합에 비해 데이터가 너무 적어 대부분의 조합을 한 번도 보지 못하는 문제. [p6#lv3]
- HMM (용어) — Hidden Markov Model, 은닉 마르코프 모델. 보이지 않는 상태의 흐름을 확률로 모델링하는 통계 모델. [p6#lv3]
- 자연어 처리의 학문적 바탕 (개념) — 자연어 처리를 이루는 언어학(문법·의미론·화용론), 컴퓨터 과학(알고리즘·데이터 구조), 통계·수학(확률 모델·벡터 공간), 인공지능(머신러닝·딥러닝). [p7#lv1]
- 불용어 제거와 원형 찾기 (방법) — 분석에 도움이 적은 흔한 단어를 빼고, 단어를 어간이나 사전 기본형(표제어)으로 바꿔 같은 단어를 하나로 모으는 전처리. [p7#lv3]
- 자연어 (개념) — 프로그래밍 언어와 달리 사람이 일상에서 쓰는 언어. [p7#lv1]
- 의미론 (용어) — 단어와 문장의 뜻을 다루는 언어학 분야. [p7#lv1]
- 화용론 (용어) — 맥락 속에서 말이 어떻게 쓰이는지 다루는 언어학 분야. [p7#lv1]
- 토큰 (용어) — 분석의 최소 단위로 나눈 조각. 단어·형태소·글자·부분 단어 등. [p7#lv2]
- 어절 (용어) — 띄어쓰기로 나뉜 덩어리. 한국어에서는 조사·어미가 붙어 있음. [p7#lv2]
- 교착어 (용어) — 어근에 조사·어미 같은 형태소가 붙어 문법을 나타내는 언어. [p7#lv2]
- 품사 태깅 (개념) — 토큰마다 명사·동사·조사 같은 품사를 붙이는 일. [p7#lv2]
- 어간 추출 (개념) — 규칙으로 접사를 잘라 어간만 남기기. 결과가 실제 단어가 아닐 수 있음. [p7#lv3]
- 표제어 추출 (개념) — 형태 분석으로 사전의 기본형을 찾기. 늘 실제 단어를 돌려줌. [p7#lv3]
- NLTK (개념) — 토큰화, 품사 태깅, 구문 분석, WordNet 기반 의미 분석, 텍스트 분류, 말뭉치 관리를 제공하는 교육 친화적 파이썬 자연어 처리 패키지. [p8#lv1]
- 영어 텍스트 전처리 (방법) — 소문자 변환, 단어·문장 토큰화, 구두점 제거, 불용어 제거로 영어 원문을 분석용 토큰 목록으로 바꾸는 절차. [p8#lv2]
- 품사 태깅과 빈도 분석 (방법) — 토큰에 문법적 역할(품사)을 붙이고, 전처리된 단어의 출현 횟수를 세어 핵심어를 찾는 분석. [p8#lv3]
- 워드넷 (용어) — 뜻이 같은 단어 묶음과 단어 간 관계를 담은 영어 어휘 데이터베이스(WordNet). [p8#lv1]
- 구문 분석 (개념) — 문장의 문법 구조(주어·동사·목적어 등)를 파악해 트리로 나타내는 분석. [p8#lv1]
- 구두점 (용어) — 마침표·쉼표·느낌표처럼 문장을 끊거나 꾸미는 기호. [p8#lv2]
- 문장 토큰화 (개념) — 긴 글을 문장 단위로 나누는 일(sent_tokenize). [p8#lv2]
- 품사 태깅 (개념) — 토큰마다 명사·동사·형용사 같은 문법적 역할(품사)을 붙이는 일(POS tagging). [p8#lv3]
- 한국어의 교착어적 특성 (개념) — 어근에 조사·어미 등 접사가 결합하고, 어순이 자유로우며, 조사·어미 체계가 문법 기능을 담당하는 한국어의 특성. [p9#lv1]
- 한국어 형태소 분석기 (개념) — KoNLPy가 묶어 제공하는 Okt, Mecab, Komoran, Kkma, Hannanum 등 한국어 형태소 분석기와 그 선택 기준. [p9#lv2]
- 말뭉치와 사용자 사전 (개념) — 분석기의 학습·평가에 쓰는 대규모 텍스트 집합(말뭉치)과, 분석기에 새 단어를 알려 주는 사용자 정의 사전. [p9#lv3]
- 띄어쓰기(공백) 기준으로 자르기 (방법) — 띄어쓰기(공백) 기준으로 자르기 [p9#duel]
- 형태소 분석으로 자르기 (방법) — 형태소 분석으로 자르기 [p9#duel]
- "영화" 리뷰를 찾아낸 비율(재현율) (지표) — "영화" 리뷰를 찾아낸 비율(재현율) [p9#duel]
- 조사 (용어) — 체언 뒤에 붙어 문법 관계나 뜻을 더하는 말(격조사·보조사·접속조사). [p9#lv1]
- 어미 (용어) — 용언의 어간 뒤에 붙어 활용하는 부분(종결·연결·전성·선어말 어미). [p9#lv1]
- KoNLPy (용어) — 한국어 자연어 처리 파이썬 라이브러리. Okt·Mecab·Komoran·Kkma·Hannanum을 묶어 제공. [p9#lv3]
- 형태소 분석기 (용어) — 문장을 형태소로 나누고 품사를 붙이는 프로그램. [p9#lv2]
- 말뭉치 (용어) — 자연어 처리를 위해 모은 대규모 텍스트 집합. [p9#lv3]
- 사용자 사전 (용어) — 분석기에 신조어·전문용어·고유명사를 알려 주는 사전. [p9#lv3]
- 미등록어 (용어) — 사전이나 학습 어휘에 없는 단어. [p9#lv3]
- 워드 임베딩 (개념) — 단어를 컴퓨터가 계산할 수 있는 숫자 벡터로 바꾸되, 단어 사이의 의미 관계까지 거리와 방향으로 담는 기술. [p10#lv1]
- 희소 표현과 밀집 표현 (개념) — 어휘 크기만큼 차원이 늘고 대부분이 0인 원핫(희소) 표현과, 낮은 고정 차원에 의미 정보를 압축한 워드 임베딩(밀집) 표현의 비교. [p10#lv2]
- 워드 임베딩 구축 절차 (방법) — 텍스트 전처리, 어휘 집합 구축·인덱싱(PAD·UNK·SOS·EOS 특수 토큰), 임베딩 학습과 하이퍼파라미터 최적화, 다운스트림 과제 적용의 4단계. [p10#lv3]
- 원핫 인코딩 (개념) — 어휘 크기의 벡터에서 그 단어 자리만 1, 나머지는 0으로 쓰는 표현. [p10#lv1]
- 워드 벡터 (개념) — 단어를 100~300차원의 실수로 나타낸 밀집 벡터. 뜻이 가까우면 가까이. [p10#lv1]
- 희소 벡터 (개념) — 대부분의 자리가 0인 벡터. 원핫 벡터가 대표적. [p10#lv2]
- 밀집 표현 (용어) — 모든 자리가 의미 있는 실수로 채워진 촘촘한 벡터 표현. [p10#lv1]
- 밀집 벡터 (개념) — 모든 자리에 의미 있는 숫자가 들어 있는 낮은 차원의 벡터(dense vector). [p10#lv2]
- 어휘집 (용어) — 분석에 쓰는 고유 단어 목록과 각 단어에 붙인 번호(vocabulary). [p10#lv3]
- UNK (용어) — unknown 토큰. 어휘집에 없는 단어를 대신하는 특수 토큰. [p10#lv3]
- 하이퍼파라미터 (용어) — 학습 전에 사람이 정하는 설정값(차원, 학습률, 반복 횟수 등). [p10#lv3]
- 빈도 분석 (방법) — 단어의 출현 횟수를 세는 분석. 단순 빈도, 정규화 빈도, 상대 빈도, 이진 빈도 등이 있으며 불용어와 문서 길이에 편향될 수 있다. [p11#lv1]
- TF-IDF (방법) — 문서 안 단어 빈도(TF)에 전체 문서에서의 희귀도(IDF = log(N ÷ df))를 곱해 문서별 단어 중요도를 매기는 방법. [p11#lv2]
- TF-IDF 가중치 조정 (방법) — 원시·정규화·로그·이중 정규화 TF와 기본·스무딩·확장·확률적 IDF, L2 정규화와 특성 수 제한 등 TF-IDF의 가중치 변형. [p11#lv3]
- TF-IDF 1위 단어 (방법) — TF-IDF 1위 단어 [p11#duel]
- 가장 많이 나온 단어 (방법) — 가장 많이 나온 단어 [p11#duel]
- 핵심어를 맞힌 비율 (지표) — 핵심어를 맞힌 비율 [p11#duel]
- 정규화 빈도 (용어) — 단어 횟수를 문서 길이로 나눈 비율. 길이가 다른 문서를 공정하게 비교한다. [p11#lv1]
- 이진 빈도 (용어) — 단어가 문서에 나왔으면 1, 아니면 0으로 표시하는 빈도. [p11#lv1]
- TF (용어) — 문서 안 단어 빈도. 보통 문서 길이로 나눔. [p11#lv2]
- IDF (용어) — 역문서 빈도 log(N ÷ df). 그 단어가 나온 문서가 적을수록 큼. [p11#lv2]
- 로그 스케일링 (개념) — TF에 로그를 씌워(1 + log f) 많은 반복의 효과를 줄이는 조정. [p11#lv3]
- 스무딩 (개념) — 분자·분모에 1 같은 작은 값을 더해 0이나 극단값을 막는 조정. [p11#lv3]
- 워드 임베딩의 발전 (개념) — 빈도 기반(TF-IDF)에서 LSA, LDA 같은 확률 모델링, Word2Vec·GloVe 신경망 임베딩, BERT·GPT 문맥화 임베딩, 추론 기반 임베딩으로 이어진 흐름. [p12#lv1]
- LDA 토픽 모델 (방법) — 문서를 토픽의 혼합, 토픽을 단어 분포로 보고, 관찰한 단어로부터 문서-주제 분포 θ와 주제-단어 분포 φ를 추정하는 확률적 토픽 모델. [p12#lv2]
- LDA 결과 해석 (방법) — 문서-주제 분포(θ), 주제 간 거리 지도(원 크기 = 비중, 거리 = 유사성), 주제별 상위 단어와 관련성 λ로 토픽을 해석하는 방법. [p12#lv3]
- LSA (용어) — Latent Semantic Analysis, 잠재 의미 분석. 단어-문서 행렬을 압축해 숨은 의미를 뽑는 기법. [p12#lv1]
- 문맥화 임베딩 (개념) — 같은 단어도 문장 문맥에 따라 다른 벡터를 주는 임베딩(BERT, ELMo). [p12#lv1]
- 토픽 모델링 (개념) — 문서 묶음에서 숨은 주제를 자동으로 찾는 비지도 학습. [p12#lv2]
- 디리클레 분포 (개념) — 합이 1인 비율 묶음(θ, φ)을 뽑는 확률분포. α로 쏠림 정도를 정함. [p12#lv2]
- 주제 간 거리 지도 (용어) — 토픽 사이의 유사성을 2차원 거리로, 비중을 원 크기로 그린 LDA 결과 시각화. [p12#lv3]
- 관련성 λ (용어) — 주제 내 빈도(λ = 1)와 특이성(λ = 0) 사이에서 상위 단어 순위 기준을 조절하는 값. [p12#lv3]
- Word2Vec (방법) — 주변 단어를 예측하는 작은 신경망을 학습해 단어마다 100~300차원의 밀집 벡터를 얻는 단어 임베딩 방법. 분포 가설에 바탕을 둔다. [p14#lv1]
- Word2Vec 학습 효율화 (방법) — 대상 단어와 몇 개의 부정 샘플만 학습하는 네거티브 샘플링(보통 5~20개)과, 이진 트리로 계산량을 O(V)에서 O(log V)로 줄이는 계층적 소프트맥스. [p14#lv2]
- 단어 벡터 연산과 시각화 (개념) — 단어 벡터의 덧셈·뺄셈으로 의미 관계를 추론하고, PCA·t-SNE로 고차원 벡터를 2·3차원에 그려 군집·방향·편향을 살피는 일. [p14#lv3]
- 분포 가설 (개념) — 비슷한 문맥에 등장하는 단어는 비슷한 의미를 가진다는 가설(J.R. 퍼스). [p14#lv1]
- CBOW (용어) — 주변 단어로 가운데 단어를 맞히는 Word2Vec 학습 방식. [p14#lv1]
- Skip-gram (개념) — 가운데 단어로 주변 단어를 맞히는 Word2Vec 학습 방식. [p14#lv1]
- 네거티브 샘플링 (개념) — 정답 단어와 무작위 부정 샘플 몇 개만 구분하게 해 Word2Vec 학습을 빠르게 하는 기법. [p14#lv2]
- 계층적 소프트맥스 (개념) — 어휘를 이진 트리로 만들어 확률 계산량을 O(V)에서 O(log V)로 줄이는 기법. [p14#lv2]
- 윈도우 크기 (용어) — 가운데 단어 주변 몇 단어까지를 문맥으로 볼지 정하는 값(보통 5~10). [p14#lv2]
- PCA (용어) — 주성분 분석. 분산이 가장 큰 방향의 축으로 투영하는 선형 차원 축소. [p14#lv3]
- t-SNE (개념) — 가까운 점의 이웃 구조를 지키며 2·3차원으로 줄이는 비선형 차원 축소. [p14#lv3]
- 편향 (용어) — 학습 데이터에 담긴 사회적 고정관념이 벡터에 남는 현상. [p14#lv3]

- 콘텐츠 기반 필터링 (개념) — 사용자가 본 콘텐츠와 내용이 비슷한 다른 콘텐츠를 추천하는 방법. [p16#lv1]

- 분류 모델의 평가 지표 (개념) — 분류 결과를 혼동 행렬로 정리해 정확도·정밀도·재현율·F1 등으로 평가하는 방법. 불균형 데이터에서는 F1·AUC가 더 믿을 만하다. [p17#lv3]
- 분류 (개념) — 텍스트를 미리 정한 범주 중 하나(또는 여러 개)로 나누는 문제. [p17#lv1]
- 회귀 (개념) — 텍스트로부터 연속적인 수치를 예측하는 문제. [p17#lv1]
- MAE (용어) — Mean Absolute Error, 평균 절대 오차. 예측과 실제의 차이(절댓값)의 평균. [p17#lv1]
- RMSE (용어) — Root Mean Squared Error, 평균 제곱근 오차. 큰 오차에 더 민감. [p17#lv1]
- 로지스틱 회귀 (개념) — 특성의 가중합을 시그모이드 함수로 0~1 확률로 바꿔 분류하는 모델. [p17#lv2]
- 시그모이드 (용어) — 어떤 수든 0과 1 사이 값으로 바꾸는 S자 함수 1 ÷ (1 + e^(−z)). [p17#lv2]
- BoW (용어) — Bag of Words. 단어의 출현 횟수만 세고 순서는 무시하는 벡터화. [p17#lv2]
- 분류 모델 (개념) — 텍스트를 미리 정한 범주(긍정·부정, 스팸·정상)로 나누는 모델. [p17#lv3]
- 회귀 모델 (개념) — 텍스트로부터 연속적인 수치(평점, 감정 점수)를 예측하는 모델. [p17#lv3]
- 정밀도 (용어) — "그렇다"고 판정한 것 중 진짜 그런 것의 비율. [p17#lv3]

- F1 (용어) — 정밀도와 재현율의 조화평균. 불균형 데이터에서 정확도보다 믿을 만함. [p17#lv3]
- 인공 뉴런과 활성화 함수 (개념) — 여러 입력에 가중치를 곱해 더하고(편향 포함) 활성화 함수(시그모이드, tanh, ReLU)로 비선형성을 부여해 출력하는 신경망의 기본 계산 단위. [p18#lv1]
- 순환 신경망과 기울기 소실 (개념) — 이전 은닉 상태를 현재 입력과 결합해 다음 은닉 상태를 만드는 순환 구조와, 긴 시퀀스에서 기울기가 거듭제곱으로 약해지거나 커지는 소실·폭주 문제. [p18#lv2]
- RNN과 LSTM (방법) — 이전 시점의 은닉 상태를 다음 시점에 넘기며 순서 데이터를 처리하는 순환 신경망(RNN)과, 셀 상태·망각·입력·출력 게이트로 장기 기억을 지키는 LSTM. [p18#lv3]
- LSTM(망각 게이트 0.97) (방법) — LSTM(망각 게이트 0.97) [p18#duel]

- 뉴런 (개념) — 입력의 가중합에 활성화 함수를 적용해 출력하는 신경망의 계산 단위. [p18#lv1]
- 활성화 함수 (용어) — 뉴런 출력에 비선형성을 주는 함수(시그모이드, tanh, ReLU). [p18#lv1]
- ReLU (용어) — Rectified Linear Unit. 음수는 0, 양수는 그대로 내보내는 활성화 함수. [p18#lv1]
- RNN (용어) — 순환 신경망. 이전 은닉 상태를 다음 시점에 넘기며 순서를 처리. [p18#lv3]
- 은닉 상태 (용어) — RNN이 지금까지 읽은 내용을 담아 다음 시점에 넘기는 벡터. [p18#lv3]
- 기울기 소실 (용어) — 긴 순서를 거꾸로 거치며 학습 신호가 거듭 곱해져 사라지는 현상. [p18#lv3]
- LSTM (용어) — 셀 상태와 망각·입력·출력 게이트로 장기 기억을 지키는 RNN. [p18#lv3]
- Seq2Seq 인코더-디코더 구조 (개념) — 인코더가 입력 시퀀스를 문맥 벡터로 압축하고, 디코더가 문맥 벡터와 이전 출력으로 목표 시퀀스를 자기회귀적으로 생성하는 구조. [p19#lv1]
- Seq2Seq(인코더-디코더) (방법) — 인코더가 입력 시퀀스를 고정 길이 문맥 벡터로 압축하고 디코더가 그 벡터로부터 출력 시퀀스를 자기회귀적으로 생성하는 모델. [p19#lv2]

- 디코더 (용어) — 문맥 벡터와 이전 출력으로 목표 시퀀스를 한 단어씩 생성하는 Seq2Seq의 뒷부분. [p19#lv1]

- 뜻으로 찾기 (개념) — 질문의 좌표와 가까운 좌표를 가진 글을 찾는 방법. [p11#lv2]
- 값과 성적의 엇갈림 (개념) — 더 많이 맞히는 방법일수록 요청마다 읽는 글이 많아지는 경향. [p12#lv1]
- 섞어 쓰기 (방법) — 최근 원문, 요점, 꺼내 읽기를 한 창에 층으로 겹쳐 쓰는 방법. [p12#lv2]
- 조각 예산 (개념) — 창 하나를 층마다 얼마씩 나눠 쓸지 정한 것. [p12#lv2]
- 기억의 층 (개념) — 최근 원문 층, 요점 층, 꺼내 읽기 층처럼 맡은 일이 다른 기억의 겹. [p12#lv2]
- 사실 기억 (의미 기억) (개념) — 무엇이 어떠한지에 관한 기억. 답의 근거가 된다. [p13#lv1]
- 경험 기억 (일화 기억) (개념) — 전에 어떻게 했더니 어떻게 됐는지에 관한 기억. 본보기로 쓴다. [p13#lv1]
- 하는 법 기억 (절차 기억) (개념) — 말투와 일하는 방식에 관한 기억. 늘 적용한다. [p13#lv1]
- 너무 많이 적기 (과잉 추출) (개념) — 쓸모없는 말까지 적어 서랍을 흐리는 것. 정밀도가 떨어진다. [p13#lv2]
- 너무 적게 적기 (과소 추출) (개념) — 필요한 말을 적지 않아 서랍에 없는 것. 재현율이 떨어진다. [p13#lv2]
- 정밀도와 재현율 (개념) — 적은 쪽지 가운데 쓸모 있는 비율과, 쓸모 있는 말 가운데 적어 둔 비율. [p13#lv2]
- 대화 중에 적기 (개념) — 대화가 진행되는 동안 바로 기억을 저장하는 방식. [p14#lv1]
- 대화 뒤에 적기 (개념) — 대화가 끝난 뒤 돌아보며 기억을 뽑아 저장하는 방식. [p14#lv1]
- 적느라 늘어나는 기다림 (개념) — 기억을 고르고 저장하는 동안 답이 늦어지는 시간. [p14#lv1]
- 프로필 (한 장에 고쳐 쓰기) (개념) — 주제마다 한 칸을 두고 새 정보가 오면 그 칸을 고쳐 쓰는 기억. [p14#lv2]
- 모음 (쪽지 더하기) (개념) — 새 정보가 올 때마다 기록을 하나씩 더하고 필요할 때 찾아 쓰는 기억. [p14#lv2]
- 기억 돌보기 (유지) (개념) — 어긋난 기억을 찾고, 지금 맞는 것을 표시하고, 이력을 남기는 일. [p15#lv1]
- 어긋난 쪽지 (개념) — 같은 주제인데 내용이 다른 옛 기록과 새 기록. [p15#lv1]
- 덮어쓰기 (방법) — 옛 기록을 새 내용으로 바꾸는 처리. 이력은 사라진다. [p15#lv2]
- 낡음 표시하기 (방법) — 옛 기록을 지우지 않고 언제까지 맞았는지 표시해 두는 처리. [p15#lv2]
- 지식 그래프 (개념) — 대상과 관계를 뽑아 “누가 — 무슨 관계 — 무엇”으로 이어 둔 기록. [p15#lv2]
- 언제 맞았는지 적기 (개념) — 기록마다 그 내용이 맞았던 기간을 함께 적어 두는 것. [p15#lv2]
- Memorilla (방법) — 저장된 문서 전체에서 질문에 필요한 것을 고정된 수의 기억 토큰으로 모아 모델에 넘기는 기억 장치. [p16#lv1]
- 기억 토큰 (개념) — 글이 아니라 모델의 입력 자리에 바로 넣는 숫자 묶음. Memorilla는 16개를 쓴다. [p16#lv1]
- 질문을 보고 만드는 기억 (개념) — 질문이 온 뒤에 그 질문에 맞게 꺼내어 줄이는 기억. 질문을 모르고 미리 줄이는 요약과 다르다. [p16#lv1]
- 손대지 않는 모델 (개념) — 가중치를 바꾸지 않고 그대로 쓰는 모델. [p16#lv1]
- 성적표 끝까지 읽기 (개념) — 평균이나 대표 수치만 보지 않고 시험별로 앞선 곳과 뒤진 곳을 가르는 읽기. [p16#lv2]
- 에이전트 (개념) — 스스로 다음 행동을 정하며 여러 단계의 일을 해 나가는 AI. [p17#lv1]
- 경험 기억 (개념) — 자기가 한 행동과 그 결과를 적어 두고 다음 행동에 쓰는 기억. [p17#lv1]
- 가 본 방 목록 (개념) — 지나온 곳을 적어 둔 가장 단순한 경험 기억. [p17#lv1]
- 맴돌기 (개념) — 지나온 곳을 기억하지 못해 같은 곳을 되풀이해 가는 것. [p17#lv1]
- 글로 하는 게임 (TextWorld) (개념) — 방 설명을 글로 읽고 행동을 글로 적어 목표를 이루는 게임 환경. [p17#lv2]
- 길이 (얼마나 멀리) (개념) — 얼마나 먼 과거의 정보가 답에 닿을 수 있는가. [p18#lv1]
- 충실도 (얼마나 정확히) (개념) — 닿은 정보가 얼마나 원래 내용 그대로인가. [p18#lv1]
- 갱신 (얼마나 지금에 맞게) (개념) — 바뀐 사실이 얼마나 빨리, 틀림없이 반영되는가. [p18#lv1]
- 모델의 기억과 시스템의 기억 (개념) — 모델 스스로 가진 것(가중치와 창)과, 모델을 둘러싼 장치가 넣어 주는 것의 구분. [p18#lv1]

- 실행 기반 채점 (방법) — 생성한 코드를 실제로 실행해 숨은 테스트 통과 여부로 채점하는 방법. [p1#lv3]
- 쌍대 선호 평가 (방법) — 이름을 가린 두 답 중 나은 쪽에 투표하게 하고 승패 기록으로 순위를 매기는 방법. [p1#lv4]
- 시험지 지키기 (개념) — 새 시험지, 비공개·교체 문제, 오차막대로 점수의 부풀림과 흔들림을 막는 일. [p1#lv5]
- 벤치마크 (개념) — 여러 모델에 똑같이 내는 공용 시험지와 채점 규칙. [p1#map]
- few-shot (개념) — 문제 앞에 예시 몇 개를 보여 주고 풀게 하는 방식. 학습이 아니라 보여 주기다. [p1#lv5]
- LLM 심판 (방법) — 더 강한 언어모델에게 답의 품질을 채점하게 하는 방법. 위치·길이 편향이 있다. [p1#lv4]
- 길이 편향 (개념) — 내용과 무관하게 긴 답을 더 좋게 보는 경향. [p1#lv4]
- 위치 편향 (개념) — 먼저(또는 나중에) 보여 준 답을 더 좋게 보는 경향. [p1#lv4]
- 오염 (개념) — 공개된 시험 문제가 모델의 학습 데이터에 섞여 점수가 부풀려지는 일. [p1#lv5]
- 여러 버전 중 최고만 남기기 (개념) — 비공개로 여러 버전을 시험해 가장 잘 나온 것만 공개하는 일. 시험지로 모델을 고르는 셈이다. [p1#duel]
- 군집 표준오차 (개념) — 문항끼리 연관(같은 지문 등)이 있을 때 오차막대를 넓혀 잡는 계산. [p1#lv5]
- F1 (지표) — 정밀도와 재현율의 조화평균. 둘 중 하나만 높으면 낮게 나온다. [p1#lv1]
- pass@k (지표) — k번 기회 중 한 번이라도 테스트를 통과할 확률. k가 크면 같은 모델 점수가 올라간다. [p1#lv3]
- 정답 대조 (지표) — 최종 답(보기, 숫자)이 정답과 같은지만 보는 채점. [p1#lv3]
- Bradley-Terry 점수 (지표) — 승패 기록에서 추정한 모델별 실력 점수. [p1#lv4]
- Bradley-Terry 모델 (방법) — 두 선수의 실력 차로 이길 확률을 정하는 모델. 승패 기록에서 실력 점수를 거꾸로 계산한다. [p1#lv4]
- MMLU (데이터) — 57과목 4지선다 지식 시험. 15,908문항을 dev·val·test로 나눴다. [p1#map]
- GPQA (데이터) — 생물·물리·화학 박사급 객관식. 전문가가 쓰고 검수했다. [p1#map]
- SWE-bench Verified (데이터) — 실제 깃허브 이슈 500개, 사람이 검수한 코딩 시험지. [p1#lv3]
- HumanEval (데이터) — 손으로 쓴 파이썬 함수 문제 164개. [p1#lv3]
- Chatbot Arena (데이터) — 이름을 가린 두 모델 답에 사람이 투표하는 공개 평가 플랫폼. [p1#lv4]
- MT-Bench (데이터) — 여러 턴 대화 문제 80개, LLM 심판 연구에 쓰였다. [p1#lv4]
- LiveBench (데이터) — 매달 문제 일부를 바꾸고 객관적 정답으로 자동 채점하는 시험지. [p1#lv5]
- GSM8k (데이터) — 초등 수학 문장제 약 8.5천 개. [p1#lv5]
- GSM1k (데이터) — GSM8k와 같은 난이도로 사람이 새로 만든 1,250문항. [p1#lv5]
- 문턱 (용어) — 확률이 이 값 이상이면 "악플"로 판정하는 기준값. [p1#lv1]
- 개발용·시험용 분리 (개념) — 프롬프트와 few-shot 예시를 고르고 다듬는 데만 쓰는 문항 묶음. 마지막에 한 번 여는 시험용과 섞지 않는다. [p1#lv5]
- Wilson 구간 (개념) — 정답률의 신뢰구간을 구하는 보정 공식. 문항이 적거나 정답률이 0이나 1에 가까울 때 정규근사보다 정확하다. [p1#lv5]
- McNemar 검정 (방법) — 같은 문항에서 두 모델 중 한쪽만 맞힌 개수를 비교해 차이가 우연인지 보는 검정. [p1#practice]
- 공격 성공률 (지표) — 해로운 응답을 끌어내려는 시도 중 성공한 비율. 낮을수록 안전하다. [p1#other]
- 과제 해결률 (지표) — 에이전트가 맡은 과제를 테스트로 확인했을 때 해결한 비율. 여러 번 돌린 평균을 쓴다. [p1#other]
- SimpleQA F-score (지표) — 전체 정답률과 시도한 것 중 정답률의 조화평균. [p1#other]
- SimpleQA (데이터) — 짧은 사실 질문 4,326개로 지어내기(환각)를 재는 시험지. [p1#other]
- HarmBench (데이터) — 해로운 행동 510개로 공격과 거절을 재는 안전 시험지. [p1#other]
- Terminal-Bench 2.0 (데이터) — 도커 컨테이너 속 터미널 과제 89개로 에이전트를 재는 시험지. [p1#other]
