- 표본오차와 오차범위 (개념) — 전체(모집단) 대신 일부(표본)를 조사해서 생기는 우연한 차이. 95% 오차범위는 약 1.96 × √(p(1−p)/n). [p1#lv2]
- 대수의 법칙 (이론) — 같은 시행을 많이 되풀이할수록 실제 비율이 이론적 확률에 가까워진다는 법칙. [p1#lv3]
- 평균 (개념) — 모든 값을 더해 개수로 나눈 값. 데이터의 가운데를 나타냄. [p1#lv1]
- 변동계수 (개념) — 표준편차 ÷ 평균 × 100%. 평균이 다른 집단의 상대적 기복을 비교. [p1#lv1]
- 왜도 (개념) — 분포가 한쪽으로 치우친 정도. 오른쪽 꼬리가 길면 양의 왜도, 0이면 좌우 대칭. [p1#lv1]

- 오차범위 (개념) — 표본 결과에 붙이는 우연한 오차의 폭. 1,000명 비율 조사면 95% 기준 약 ±3.1%. [p1#lv2]
- 중심극한정리 (개념) — 표본평균을 여러 번 구하면 그 분포가 종 모양(정규분포)에 가까워진다는 정리. [p1#lv2]
- t분포 (개념) — 표본이 작아 흩어짐을 표본으로 어림할 때 쓰는, 정규분포보다 꼬리가 두꺼운 분포. 자유도가 커지면 정규분포에 가까워짐. [p1#lv2]
- 체계적 위험 (용어) — 모두에게 한꺼번에 오는 위험(재해·금융위기). 분산해도 줄지 않음. [p1#lv3]
- 하우스 엣지 (용어) — 카지노가 모든 베팅에서 장기적으로 가져가는 몫의 비율. [p1#lv3]
- 독립 사건 (개념) — 한 사건이 일어났다는 사실이 다른 사건의 확률을 바꾸지 않는 관계. P(A∩B) = P(A) × P(B). [p2#lv2]
- 이항분포와 반복 시행 (분포) — n번 독립 시행에서 성공 확률 p인 사건이 k번 일어날 확률의 분포. P(X=k) = nCk p^k (1−p)^(n−k). [p2#lv3]
- 확률 (개념) — 어떤 일이 일어날 가능성을 0과 1 사이의 숫자로 나타낸 것. [p2#lv1]
- 도수론적 관점 (용어) — 같은 조건으로 무한히 반복할 때의 상대빈도로 확률을 정의하는 관점. [p2#lv1]
- 주관적 관점 (용어) — 확률을 어떤 일에 대한 믿음의 정도로 보는 관점. 베이지안 통계의 출발점. [p2#lv1]

- 배반 (개념) — 두 사건이 동시에 일어날 수 없는 관계. P(A∩B) = 0 [p2#lv2]

- 도박꾼의 오류 (용어) — 독립 시행에서 한쪽 결과가 연속되면 반대 결과가 "나올 차례"라고 믿는 착각. [p2#lv3]
- 베이즈 정리 (이론) — 사후 확률 = 가능도 × 사전 확률 ÷ 증거의 전체 확률. P(H|E) = P(E|H)P(H) / P(E). [p3#lv1]
- 나이브 베이즈 분류기 (방법) — 단어(특징)들이 분류 안에서 서로 독립이라고 가정하고, 사전 확률에 각 단어의 가능도를 곱해 분류하는 방법. [p3#lv2]
- 베이지안 순차 업데이트 (방법) — 앞 증거로 얻은 사후 확률을 다음 증거의 사전 확률로 쓰며 믿음을 차례로 고치는 방법. [p3#lv3]
- 가능도 (개념) — 가설이 참일 때 이 증거가 나올 확률. 예: 감염자가 양성일 확률 90% [p3#lv1]
- 혼동행렬 (용어) — 실제(있음/없음) × 판정(양성/음성) 네 칸 표. [p3#lv1]
- 민감도 (개념) — 실제 있는 경우를 양성으로 잡아내는 비율. TP ÷ (TP+FN) [p3#lv1]

- 독립성 가정 (개념) — 같은 분류 안에서 단어(특징)들이 서로 영향을 주지 않는다는 가정. [p3#lv2]
- A/B 테스트 (방법) — 사용자를 무작위로 두 무리로 나눠 한쪽에만 바꾼 버전을 보여 주고 지표를 비교하는 실험. [p4#lv1]
- 베이지안 평균(수축 추정) (개념) — 데이터가 적은 항목의 비율을 전체 평균 쪽으로 당겨, 우연히 튄 값을 바로잡는 추정. [p4#lv2]
- 무작위 배정 (개념) — 실험 대상을 제비뽑기처럼 나눠 다른 요인이 한쪽에 몰리지 않게 하는 것. [p4#lv1]
- 클릭률 (개념) — 클릭 ÷ 노출. [p4#lv1]
- 전환율 (개념) — 구매(목표 행동) ÷ 클릭 또는 방문. [p4#lv1]
- 콜드 스타트 (용어) — 새 사용자·새 항목이라 데이터가 적어 추천이 어려운 문제. [p4#lv2]
- 사전분포 (개념) — 데이터를 보기 전 값에 대한 믿음을 분포로 나타낸 것. [p4#lv3]
- 사후분포 (개념) — 데이터를 반영한 뒤의 믿음을 분포로 나타낸 것. [p4#lv3]
- 실용적 유의성 (용어) — 차이가 확실해도 비용·효과 면에서 의미가 있는지 따로 따지는 것. [p4#lv3]
- MCMC (용어) — 마르코프 체인 몬테카를로. 복잡한 사후분포에서 표본을 뽑는 방법(8회차). [p4#lv3]
- 연관 규칙 분석 (방법) — 거래 기록에서 함께 나타나는 항목의 짝을 지지도·신뢰도·향상도로 찾는 방법. [p5#lv1]
- 추천의 목표 지표 (개념) — 추천 순위를 매길 때 최대로 하려는 값(클릭률, 시청시간, 다양성 등). 목표에 따라 추천 결과가 달라진다. [p5#lv2]
- 협업 필터링 (방법) — 사용자-항목 평점표에서 취향이 닮은 사용자(또는 항목)를 찾아 비어 있는 평점을 예측하는 추천 방법. [p5#lv3]
- 지지도 (개념) — 전체 거래 중 A와 B를 함께 산 비율. [p5#lv1]
- 신뢰도 (개념) — A를 산 거래 중 B도 산 비율. 조건부 확률 P(B|A). [p5#lv1]
- 향상도 (개념) — 신뢰도 ÷ B의 평소 구매율. 1보다 크면 함께 사는 경향. [p5#lv1]
- 필터 버블 (용어) — 알고리즘이 좋아할 만한 것만 보여 줘 시야가 좁아지는 현상. [p5#lv2]
- 다양성 (개념) — 추천 목록이 얼마나 여러 분야를 담는지. [p5#lv2]
- 콘텐츠 기반 (개념) — 항목의 특징(장르·키워드)이 내가 좋아한 것과 비슷한 항목을 추천. [p5#lv3]
- 코사인 유사도 (개념) — 두 벡터의 방향이 얼마나 같은지. 1이면 같음, 0이면 무관. [p5#lv3]
- 희소행렬 (용어) — 대부분이 빈칸(0)인 표. 채워진 칸만 저장해 메모리를 아낌. [p5#lv3]
- 행렬분해 (개념) — 큰 평점표를 숨은 취향 몇 개로 이루어진 작은 표 두 개로 나누는 방법. [p5#lv3]
- 베이지안 신용평가 (방법) — 신용등급별 연체율을 사전 확률로 두고, 소득·부채 등 정보의 우도비를 곱해 사후 연체 확률을 계산하는 심사 방법. [p6#lv1]
- 증거의 판별력(우도비) (개념) — 어떤 정보가 가설이 참일 때와 거짓일 때 나올 확률이 얼마나 다른가. 같으면(우도비 1) 믿음을 바꾸지 않는다. [p6#lv2]
- 분산투자(포트폴리오) (방법) — 함께 덜 움직이는 자산을 섞어 전체 수익률의 흔들림(위험)을 줄이는 방법. [p6#lv3]
- 신용등급 (용어) — 대출자의 상환 능력을 등급으로 나타낸 것. 등급별 연체율이 사전 확률이 됨. [p6#lv1]
- 충당금 (용어) — 돌려받지 못할 것으로 예상되는 대출을 미리 비용으로 잡아 두는 돈. [p6#lv1]
- 확증편향 (용어) — 자기 생각에 맞는 정보만 골라 믿는 경향. [p6#lv2]
- 에코챔버 (용어) — 같은 의견만 메아리치는 공간. 판단을 한쪽으로 몰아감. [p6#lv2]
- 기초자산 (용어) — 가치의 근거가 되는 실물·현금흐름(기업 이익, 채권 이자 등). [p6#lv2]
- 포트폴리오 위험 (개념) — 여러 자산을 섞은 전체 수익률의 표준편차. [p6#lv3]
- 비체계적 위험 (용어) — 개별 자산 고유의 위험. 분산투자로 줄일 수 있음. [p6#lv3]
- 리밸런싱 (용어) — 정해 둔 비중이나 바뀐 추정에 맞춰 자산 비중을 다시 맞추는 일. [p6#lv3]
- 마르코프 체인 (방법) — 다음 상태의 확률이 현재 상태에만 달려 있는(마르코프 성질) 상태 전이 모형. 전이 행렬 P로 나타낸다. [p7#lv1]
- 페이지랭크 (방법) — 링크를 무작위로 따라가는 서퍼가 오래 머무는 비율(마르코프 체인의 정상분포)로 웹페이지 중요도를 정하는 알고리즘. [p7#lv2]
- 고객 생애가치(CLV) (개념) — 한 고객이 관계를 유지하는 동안 만들어 낼 미래 매출(이익)의 현재 가치 합. [p7#lv3]
- 전이 행렬 (용어) — 행 = 지금 상태, 열 = 다음 상태인 확률표. 각 행의 합은 1. [p7#lv1]
- 정상분포 (개념) — 전이 행렬을 곱해도 변하지 않는 장기 상태 비율. π = πP. [p7#lv1]
- 1차 모형 (개념) — 지금 상태 하나로 다음을 예측. 2차는 직전 상태까지 함께 봄. [p7#lv1]
- 감쇠 계수 (용어) — 링크를 따라갈 확률(보통 0.85). 나머지는 무작위 순간이동. [p7#lv2]
- 할인율 (용어) — 미래의 돈을 현재 가치로 바꿀 때 쓰는 비율. 1/(1+r)ᵗ을 곱함. [p7#lv3]
- 세그먼트 (용어) — 비슷한 특성으로 묶은 고객 무리. [p7#lv3]
- 몬테카를로 시뮬레이션 (방법) — 불확실한 입력을 확률분포로 두고 난수로 수많이 뽑아 결과의 분포를 얻는 방법. [p9#lv1]
- 독립 위험의 누적 (개념) — 여러 독립 단계가 모두 성공해야 할 때 전체 성공 확률은 각 확률의 곱이 되어 빠르게 작아진다. [p9#lv2]
- 백분위수 (개념) — 자료를 작은 순서로 세웠을 때 몇 % 위치의 값. P10, P50, P90. [p9#lv1]
- 중앙값 (개념) — 가운데 위치의 값(P50). 한쪽 꼬리가 길면 평균과 달라짐. [p9#lv1]
- 삼각분포 (개념) — 최솟값·최빈값·최댓값 세 숫자로 정하는 분포. 전문가 추정에 자주 씀. [p9#lv1]
- 민감도 분석 (개념) — 입력 하나를 바꿀 때 결과가 얼마나 바뀌는지 보는 분석. [p9#lv1]
- 안전재고 (용어) — 수요·공급의 흔들림에 대비해 더 쌓아 두는 재고. [p9#lv2]
- 메트로폴리스 (개념) — 후보를 제안하고 사후 확률의 비율로 받아들일지 정하는 MCMC 알고리즘. [p9#lv3]
- 번인 (용어) — MCMC에서 아직 수렴하지 않은 앞부분 표본을 버리는 것. [p9#lv3]
- 궤적 그림 (용어) — MCMC 표본을 순서대로 그린 그림. 수렴과 섞임을 눈으로 확인. [p9#lv3]
- 확률의 곱셈 법칙(사슬) (개념) — 여러 단계를 차례로 거치는 사건의 확률은 각 단계 조건부 확률의 곱. P(구매|노출) = P(클릭|노출) × P(구매|클릭). [p10#lv1]
- 양성 예측도(PPV) (개념) — 검사가 양성일 때 실제로 질병이 있을 확률. 민감도·특이도와 함께 유병률(사전 확률)에 크게 달려 있다. [p10#lv2]
- 베이지안 네트워크 (방법) — 변수를 노드로, 영향 관계를 방향 있는 화살표로 그리고, 노드마다 부모 값에 따른 조건부 확률표를 붙인 확률 모형. 일부를 관찰하면 나머지의 확률을 추론한다. [p10#lv3]
- 퍼널 (용어) — 노출 → 클릭 → 구매처럼 단계마다 줄어드는 흐름. [p10#lv1]
- 특이도 (개념) — 실제 없을 때 음성으로 판정하는 비율. TN ÷ (TN+FP) [p10#lv2]
- 유병률 (용어) — 집단 안에서 그 질병을 가진 사람의 비율. 진단의 사전 확률. [p10#lv2]
- 조건부 확률표 (용어) — 부모 노드 값의 조합마다 자식 노드의 확률을 적은 표. [p10#lv3]
- 인과 (개념) — 한쪽을 바꾸면 다른 쪽이 바뀌는 관계. 상관만으로는 말할 수 없고 설계나 가정이 필요. [p10#lv3]
- 나이브 베이즈 감성 분석 (방법) — 리뷰의 단어들을 증거로, 긍정·부정 각각의 사전 확률에 단어별 가능도를 곱해 감성 확률을 계산하는 분류. [p11#lv1]
- 비율의 신용구간 (개념) — 관찰한 성공·실패 수로 만든 베타 사후분포에서, 비율이 들어 있을 범위를 확률로 나타낸 구간. [p11#lv2]
- 토픽 모델(LDA) (방법) — 문서는 여러 토픽의 혼합, 토픽은 단어들의 확률분포라고 보고, 문서마다 토픽 비율을 베이지안으로 추정하는 방법. [p11#lv3]
- 자연어 처리 (용어) — 사람의 말과 글을 컴퓨터로 분석·생성하는 분야. [p11#lv1]
- 토큰화 (용어) — 문장을 단어·형태소 같은 작은 단위로 나누는 일. [p11#lv1]
- 라플라스 평활 (개념) — 모든 단어 횟수에 1을 더해 확률 0을 막는 방법. [p11#lv1]
- 토픽 (용어) — 함께 자주 나오는 단어들의 확률분포. 사람이 상위 단어를 보고 이름을 붙임. [p11#lv3]
- 베이지안 해시태그 추천 (방법) — 태그 인기도를 사전 확률, 사진 특징이 그 태그의 사진에서 나올 확률을 가능도로 두고, 사후 확률이 높은 태그를 추천하는 방법. [p12#lv1]
- 진단 불확실성 (개념) — 검사 성능(민감도·특이도), 유병률, 판독자 차이에서 오는 판정의 불확실성. 확률과 범위로 표현해 결정 기준과 비교한다. [p12#lv2]
- MC 드롭아웃 (방법) — 테스트 때도 드롭아웃을 켠 채 같은 입력을 여러 번 예측해, 예측의 평균과 흔들림(표준편차)으로 모델의 불확실성을 어림하는 베이지안 근사 방법. [p12#lv3]
- 신뢰구간 (개념) — 같은 방법으로 반복하면 그중 약 95%가 참값을 포함하는 구간(빈도주의). "이 구간에 참값이 있을 확률 95%"로 읽지 않음. [p12#lv2]
- 드롭아웃 (개념) — 학습 때 신경망의 일부를 무작위로 꺼서 과적합을 막는 장치. [p12#lv3]
- Aleatoric (용어) — 데이터 자체의 흔들림(조명·잡음). 데이터를 늘려도 줄지 않음. [p12#lv3]
- Epistemic (용어) — 모델이 몰라서 생기는 흔들림. 데이터를 늘리면 줄어듦. [p12#lv3]
- 능동 학습 (개념) — 모델이 가장 헷갈린 사례를 골라 라벨을 달아 학습하는 방법. [p12#lv3]
- 포아송 분포 (분포) — 일정 시간·공간에서 독립적으로 일어나는 사건의 횟수 분포. 평균 λ 하나로 정해지며 평균과 분산이 같다. [p13#lv1]
- 계층적 베이지안 모델 (방법) — 무리(매장·지역)마다의 모수가 전체 분포에서 나온다고 보고, 전체 경향과 무리별 차이를 함께 추정하는 모형. 기록이 적은 무리는 전체 정보로 보완된다(수축). [p13#lv2]
- 평가자 효과 보정 (방법) — 점수 = 개인 실력 + 평가자 효과 + 우연으로 보고, 평가자 층의 차이를 추정해 걸러 내는 계층적 분석. [p13#lv3]
- 매장 평균 그대로(따로) (방법) — 매장 평균 그대로(따로) [p13#duel]
- 계층 모델(부분 풀링) (방법) — 계층 모델(부분 풀링) [p13#duel]
- 진짜 매장 평균과의 평균 오차 (지표) — 진짜 매장 평균과의 평균 오차 [p13#duel]
- 노이즈 (용어) — 진짜 패턴이 아닌 우연한 흔들림. [p13#lv1]
- 수축 (개념) — 기록이 적은 무리의 추정을 전체 평균 쪽으로 당기는 효과. [p13#lv1]
- 부분 풀링 (개념) — 무리마다 따로도, 모두 하나로도 아닌 중간. 전체 정보로 무리를 보완. [p13#lv2]
- 완전 풀링 (개념) — 모든 무리를 하나로 보고 같은 값으로 추정. [p13#lv2]
- 평가자 효과 (용어) — 같은 대상을 평가자마다 후하게·엄격하게 매기는 차이. [p13#lv3]
- 평균으로의 회귀 (개념) — 첫 측정이 극단이었던 대상은 다음 측정에서 평균 쪽으로 돌아오는 경향. [p13#lv3]
- 디리클레 분포 (분포) — 여러 카테고리 비율(합이 1)에 대한 믿음을 나타내는 분포. 사전 α에 관찰 횟수를 더하면 사후 α가 된다(베타 분포의 여러 칸 버전). [p14#lv1]
- 베이지안 A/B와 단계적 적용 (방법) — 두 안의 전환율 사후분포로 P(B>A)와 기대 개선을 계산하고, 남은 위험에 맞춰 적용 범위를 단계적으로 넓히는 의사결정 방법. [p14#lv2]
